# Step 3 — Affects Versions Correction: TC-8001

## Correction Details

- **Current Affects Versions**: RHTPA 2.0.0
- **Proposed Affects Versions**: RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2
- **Reason**: PSIRT-assigned "RHTPA 2.0.0" does not match any configured version stream. Lock file analysis confirms versions 2.2.0, 2.2.1, and 2.2.2 in the 2.2.x stream ship quinn-proto < 0.11.14 (the vulnerable range). Versions 2.2.3 and 2.2.4 ship the fixed version (0.11.14) and are excluded. Scoped to stream 2.2.x per issue suffix [rhtpa-2.2].
