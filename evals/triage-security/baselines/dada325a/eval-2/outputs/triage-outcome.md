# Triage Outcome — TC-8002 (CVE-2026-28940, serde_json)

## Decision

**Case C: no supported versions are affected. Recommendation: close TC-8002 as "Not a Bug", with VEX Justification "Component not Present".**

Every supported RHTPA version already ships a patched serde_json:
- 2.1.x ships 1.0.137.
- 2.2.x ships 1.0.138 or 1.0.139.
