## 3.2 -- Compare and Correct Affects Versions

The issue is scoped to stream **2.2.x** (stream suffix `[rhtpa-2.2]`). Only versions belonging to the 2.2.x stream are included in the correction.

Based on the version impact table, affected versions within the 2.2.x stream are: 2.2.0, 2.2.1, 2.2.2.

**Affects Versions diff:**

```
Current:  [RHTPA 2.0.0]
Proposed: [RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2]
```

PSIRT assigned `RHTPA 2.0.0` which does not correspond to any version in the supportability matrix. The correction replaces it with the actually affected versions from the 2.2.x stream, verified via lock file analysis at pinned commits.

Version names are referenced from the supportability matrix rather than hardcoded Jira version IDs.
