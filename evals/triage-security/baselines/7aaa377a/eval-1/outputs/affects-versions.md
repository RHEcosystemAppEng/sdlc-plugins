# Step 3 -- Affects Versions Correction

## 3.1 -- Dynamic Version Discovery

Jira versions are discovered dynamically via API (Important Rule 6). The skill
would call:

```
jira.getJiraIssueTypeMetaWithFields(
  projectIdOrKey: "TC",
  issueTypeId: "10024"
)
```

And filter the returned `versions` field's `allowedValues` by the Jira version
prefix "RHTPA" to find available version names and their IDs at runtime. No
version IDs are hardcoded.

## 3.2 -- Proposed Affects Versions Correction

The issue is scoped to stream **2.2.x** (suffix `[rhtpa-2.2]`), so only versions
from the 2.2.x stream are included in the correction. The 2.1.x versions (also
affected) belong to a sibling issue tracking that stream.

**Current (PSIRT-assigned):** `[RHTPA 2.0.0]`

**Proposed (lock-file-verified):** `[RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2]`

**Diff:**
```
- RHTPA 2.0.0       (REMOVE -- version 2.0 does not exist in any configured stream)
+ RHTPA 2.2.0       (ADD -- quinn-proto 0.11.9 < 0.11.14, affected)
+ RHTPA 2.2.1       (ADD -- quinn-proto 0.11.12 < 0.11.14, affected)
+ RHTPA 2.2.2       (ADD -- retag of 2.2.1, same affected status)
```

Versions RHTPA 2.2.3 and RHTPA 2.2.4 are excluded because they ship
quinn-proto 0.11.14 (at or above the fix threshold).

**Rationale:** PSIRT assigned RHTPA 2.0.0 based on scan-time assessment, but
no 2.0.x stream exists in the configured Version Streams. Lock file analysis
at the pinned commits from the supportability matrix confirms that 2.2.0, 2.2.1,
and 2.2.2 are the actually affected versions within this issue's stream scope.

## Proposed Jira Mutation

After engineer confirmation, the following mutation would be executed:

```
jira.edit_issue("TC-8001", fields={
  "versions": [
    {"id": "<RHTPA-2.2.0-jira-id>"},
    {"id": "<RHTPA-2.2.1-jira-id>"},
    {"id": "<RHTPA-2.2.2-jira-id>"}
  ]
})
```

Version IDs are resolved from the dynamic version registry discovered in
Step 3.1 -- they are referenced by name (RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2)
and mapped to their Jira IDs at runtime.
