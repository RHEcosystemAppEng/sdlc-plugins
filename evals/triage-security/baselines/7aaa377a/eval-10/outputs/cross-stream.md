## Preemptive Task Creation Details

Since stream rhtpa-2.1 has no CVE Jira, per Step 8 Case A, proactive preemptive remediation tasks are created. The key differences from standard remediation tasks:

### Labels

Preemptive tasks include the `security-preemptive` label alongside standard labels:

- Standard labels: `["ai-generated-jira", "Security", "CVE-2026-55123"]`
- Preemptive labels: `["ai-generated-jira", "Security", "CVE-2026-55123", "security-preemptive"]`

### Link Type

Preemptive tasks are linked to the originating CVE Jira TC-8020 with **"Related"** link type (not "Depend"), because TC-8020 belongs to a different stream (rhtpa-2.2, not rhtpa-2.1):

```
jira.create_link(
  inwardIssue: "TC-8020",
  outwardIssue: <preemptive-task-key>,
  type: "Related"
)
```

This differs from standard remediation tasks which use "Depend" to link to their own stream's CVE Jira.

### Description Prefix

Each preemptive task description includes the preemptive remediation prefix noting the originating CVE:

```

> impact analysis of TC-8020 (stream rhtpa-2.2).
> No stream-specific CVE Jira exists yet for this stream. When PSIRT creates one,
> this task will be linked and the `security-preemptive` label removed.
```
