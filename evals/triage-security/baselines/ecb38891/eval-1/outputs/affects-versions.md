### 3.2 — Compare and Correct Affects Versions

The issue is scoped to stream **2.2.x** (suffix `[rhtpa-2.2]`). Only versions
belonging to the 2.2.x stream are included in the correction, even though the
version impact table shows 2.1.x versions are also affected — those belong to
a sibling issue for the 2.1.x stream.

**Proposed Affects Versions correction:**

```
Current:  [RHTPA 2.0.0]
Proposed: [RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2]
```

**Rationale:** PSIRT assigned RHTPA 2.0.0, which does not correspond to any
version in the supportability matrix. Lock file analysis at pinned commits
confirms:

- RHTPA 2.2.0 (tag `v0.4.5`): quinn-proto 0.11.9 — affected (< 0.11.14)
- RHTPA 2.2.1 (tag `v0.4.8`): quinn-proto 0.11.12 — affected (< 0.11.14)
- RHTPA 2.2.2 (tag `v0.4.9`): retag of 2.2.1 — affected (same as 2.2.1)
- RHTPA 2.2.3 (tag `v0.4.11`): quinn-proto 0.11.14 — NOT affected
- RHTPA 2.2.4 (tag `v0.4.12`): quinn-proto 0.11.14 — NOT affected
