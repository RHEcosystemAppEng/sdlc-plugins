### Rationale

PSIRT occasionally creates multiple Vulnerability issues for the same CVE and stream. When a same-stream sibling already exists and is open or in progress, the newer issue is closed as Duplicate per Step 4.1 of the triage-security skill. This prevents duplicate remediation work and keeps tracking consolidated in a single issue (TC-7999).
