## 3.2 -- Affects Versions Comparison and Correction

Issue is scoped to stream **2.2.x** per suffix `[rhtpa-2.2]`. Only versions from the 2.2.x stream are proposed for Affects Versions on this issue. The 2.1.x versions belong to a sibling issue (see Step 4).

**PSIRT-assigned Affects Versions are wrong.** RHTPA 2.0.0 does not exist in the configured version streams.

```
Current:  [RHTPA 2.0.0]
Proposed: [RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2]
```

Versions RHTPA 2.2.3 and RHTPA 2.2.4 are excluded because they ship quinn-proto 0.11.14 (fixed version -- not affected).

Version 2.2.2 is included because it is a retag of 2.2.1 (same source commit v0.4.8, same quinn-proto 0.11.12 which is within the affected range).

**Proposed action:** Update Affects Versions from [RHTPA 2.0.0] to [RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2] using dynamically discovered Jira version IDs (Important Rule 6 -- never hardcode version IDs).
