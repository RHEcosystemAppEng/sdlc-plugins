# Step 3 — Affects Versions Correction: TC-8001

## Proposed Correction

**Current Affects Versions**: RHTPA 2.0.0
**Proposed Affects Versions**: RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2

**Rationale**: The PSIRT-assigned version "RHTPA 2.0.0" does not correspond to any version in the supportability matrix. Lock file analysis at pinned commits from security-matrix.md shows:

- RHTPA 2.2.0 (tag `v0.4.5`): quinn-proto 0.11.9 — affected (< 0.11.14)
- RHTPA 2.2.1 (tag `v0.4.8`): quinn-proto 0.11.12 — affected (< 0.11.14)
- RHTPA 2.2.2 (tag `v0.4.9`): retag of 2.2.1 — affected (same as 2.2.1)
- RHTPA 2.2.3 (tag `v0.4.11`): quinn-proto 0.11.14 — NOT affected (>= fix threshold)
- RHTPA 2.2.4 (tag `v0.4.12`): quinn-proto 0.11.14 — NOT affected (>= fix threshold)

Scoped to stream 2.2.x per issue suffix `[rhtpa-2.2]`. Versions from other streams (2.1.x) are excluded from this correction — they belong to companion issues.
