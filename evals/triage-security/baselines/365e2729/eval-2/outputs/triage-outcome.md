# TC-8002 — Triage Outcome

## Decision

**Case C: No supported versions affected. Recommendation: close TC-8002 as "Not a Bug" (not affected), and set VEX Justification = "Component not Present".**

CVE-2026-28940 affects serde_json versions **before 1.0.135**. Every supported RHTPA version already ships a patched serde_json:

- 2.1.x ships 1.0.137.
- 2.2.x ships 1.0.138 (2.2.0, 2.2.1, and 2.2.2, which is a retag of 2.2.1).
- 2.2.x ships 1.0.139 (2.2.3, 2.2.4).

PSIRT's Affects Version, RHTPA 2.2.0, is wrong: 2.2.0 ships serde_json 1.0.138, which is already newer than the fix release. No remediation tasks are needed.
