## 3.2 -- Compare and Correct Affects Versions

### Current vs Proposed

The issue is scoped to stream `[rhtpa-2.2]`, so only 2.2.x versions are included in the Affects Versions correction.

```
Current:  [RHTPA 2.0.0]
Proposed: [RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2]
```

**Rationale**: PSIRT assigned `RHTPA 2.0.0`, which does not exist as a configured version stream. Lock file analysis at pinned commits from security-matrix.md confirms that versions 2.2.0, 2.2.1, and 2.2.2 in the 2.2.x stream ship quinn-proto versions within the affected range (< 0.11.14). Versions 2.2.3 and 2.2.4 ship quinn-proto 0.11.14, which is the fixed version, so they are excluded.

Version names are referenced from the supportability matrix and Jira version registry -- no hardcoded Jira version IDs are used.
