#### Post-creation: Description Digest Protocol

After creating the upstream backport task, the following digest procedure would be performed:

1. **Re-fetch the task description** from Jira (the description must be re-fetched from the API after `create_issue`, not computed from the description string passed to `create_issue`, because Jira normalizes content during storage):
   ```
   upstream_desc = jira.get_issue(<upstream-task-key>, fields=["description"])
   ```

2. **Write the description to a temp file and compute the SHA-256 digest** using the `scripts/sha256-digest.py` script:
   ```bash
   python3 scripts/sha256-digest.py /tmp/task-desc.md
   # Output: sha256-md:<64-char-hex> or sha256-adf:<64-char-hex>
   ```

3. **Post the digest comment** (marker: `[sdlc-workflow] Description digest:`). This comment is posted BEFORE creating issue links (Depend, Blocks) or other comments:
   ```
   jira.add_comment(<upstream-task-key>, "[sdlc-workflow] Description digest: <tagged-digest>")
   ```
   Where `<tagged-digest>` is the full output from `scripts/sha256-digest.py` (e.g., `sha256-md:<64-char-hex-digest>`).

4. **Then create issue links** (after the digest comment):
   ```
   jira.create_link(
     inwardIssue: "TC-8001",
     outwardIssue: <upstream-task-key>,
     type: "Depend"
   )
   ```
