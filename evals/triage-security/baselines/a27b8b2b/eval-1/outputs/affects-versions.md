### Proposed Correction

The PSIRT-assigned Affects Versions are incorrect. The proposed correction replaces them with lock-file-verified versions:

```
Current:  [RHTPA 2.0.0]
Proposed: [RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2]
```

**Rationale**: RHTPA 2.0.0 does not exist in the supportability matrix or Jira version registry. The actual affected 2.2.x versions are 2.2.0, 2.2.1, and 2.2.2, based on lock file analysis at pinned commits showing quinn-proto < 0.11.14. Versions 2.2.3 and 2.2.4 ship quinn-proto 0.11.14 (the fixed version) and are therefore not affected.
