## Description digest procedure (per `shared/description-digest-protocol.md`)

The same procedure runs **for every task above**: Task 1 (dependency bump), Task 2
(downstream propagation), Task 3 (upstream backport) and Task 4 (downstream
propagation). It runs **immediately after that task's `create_issue` returns**, and
**before any issue link (Depend / Related / Blocks) or any other comment** touches
that task.

1. **Create the task:** `jira.create_issue(projectKey: "TC", issueTypeName: "Task", summary, description, labels, security)`. Record the returned key.
2. **Re-fetch the stored description from Jira:**
   `jira.get_issue(<task-key>, fields=["description"])`.
   The digest is computed from **this re-fetched description**. It is **never**
   computed from the description string passed to `create_issue`, because Jira
   normalises content when it stores it. MCP returns markdown and the REST API
   returns ADF JSON.
3. **Write the re-fetched description to a temp file**, e.g. `/tmp/task-desc.md`
   (markdown via MCP) or `/tmp/task-desc.json` (ADF via REST).
4. **Compute the SHA-256 digest with the script:**
   `python3 scripts/sha256-digest.py /tmp/task-desc.md`.
   The script detects the format and prints `sha256-md:<64-hex>` or
   `sha256-adf:<64-hex>`. Check the exit code. A non-zero exit (for example an empty
   description) stops the process, and nothing is posted. Do not hash by hand. Do not
   abbreviate the hash or use a placeholder or example hash. Keep the format tag.
5. **Post the digest as its own comment** on the task, a single ADF paragraph with
   exactly one line and no added text:
   ```
   [sdlc-workflow] Description digest: <full tagged output of sha256-digest.py>
   ```
   ```json
   {"type":"doc","version":1,"content":[{"type":"paragraph","content":[
     {"type":"text","text":"[sdlc-workflow] Description digest: sha256-md:<64-hex from script>"}]}]}
   ```
   This comment is separate from every footnoted triage comment. It is not merged
   into any other comment.
6. **Only after that** may the task's links and any later comments be created.
