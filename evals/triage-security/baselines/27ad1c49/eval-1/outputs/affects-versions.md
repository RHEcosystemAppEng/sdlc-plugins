## Step 3.2 — Affects Versions Comparison and Correction

### Stream Scope

TC-8001 is scoped to the **2.2.x** stream (from summary suffix `[rhtpa-2.2]`).
Per the scoping rules, only versions belonging to the 2.2.x stream are included
in the Affects Versions correction. The 2.1.x versions (also affected) belong to
a separate stream and would be tracked by a sibling CVE issue or preemptive
remediation tasks.

### Current vs. Proposed

**Current Affects Versions**: `[RHTPA 2.0.0]`

**Issue**: RHTPA 2.0.0 does not correspond to any configured version stream.
No 2.0.x stream exists in the Version Streams table. This appears to be a
PSIRT data entry error.

**Proposed Affects Versions** (scoped to 2.2.x stream, based on version impact
table):

`[RHTPA 2.2.0, RHTPA 2.2.1, RHTPA 2.2.2]`

**Rationale**: Lock file analysis at pinned commits from the supportability matrix
confirms:
- RHTPA 2.2.0 (tag `v0.4.5`): quinn-proto 0.11.9 -- **affected** (< 0.11.14)
- RHTPA 2.2.1 (tag `v0.4.8`): quinn-proto 0.11.12 -- **affected** (< 0.11.14)
- RHTPA 2.2.2 (retag of 2.2.1): same as 2.2.1 -- **affected**
- RHTPA 2.2.3 (tag `v0.4.11`): quinn-proto 0.11.14 -- **NOT affected** (>= fix threshold)
- RHTPA 2.2.4 (tag `v0.4.12`): quinn-proto 0.11.14 -- **NOT affected** (>= fix threshold)
