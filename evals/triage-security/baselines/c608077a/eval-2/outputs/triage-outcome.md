# TC-8002 — Triage Outcome and Proposed Jira Actions

## Decision

**Case C — No supported versions affected. Close TC-8002 as "Not a Bug" with VEX
Justification "Component not Present".**

CVE-2026-28940 affects serde_json before 1.0.135. Lock-file data at the pinned backend
commits shows every supported RHTPA version already ships a patched serde_json:

- 2.1.x ships 1.0.137
- 2.2.0 to 2.2.2 ship 1.0.138
- 2.2.3 and 2.2.4 ship 1.0.139

PSIRT's claim that RHTPA 2.2.0 is affected is not supported by the evidence. 2.2.0 pins
backend `v0.4.5`, which ships serde_json 1.0.138. PSIRT most likely filed the issue from
a scanner match on the package name, not from the shipped version. No remediation tasks
are needed.
