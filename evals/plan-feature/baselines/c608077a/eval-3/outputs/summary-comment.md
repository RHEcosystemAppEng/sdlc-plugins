**Architecture summary:**
- **Backend.** `SbomService::compare` loads both SBOMs' package, license, and advisory links from the existing `sbom_package`, `package_license`, and `sbom_advisory` data, then computes a six-category diff in memory using hash sets keyed by package name and advisory ID. It adds no tables. It is exposed as `GET /api/v2/sbom/compare?left&right` in the SBOM endpoints module and returns 404 (never an empty diff) for unknown IDs.
- **Frontend.** The new `useSbomComparison` React Query hook calls the endpoint through the shared Axios client. The lazy-loaded `/sbom/compare` page keeps `left` and `right` in URL search params, so comparisons are shareable. It renders six PF5 `ExpandableSection`s, each with a per-section table, a colored count badge, `SeverityBadge`, critical-row highlighting, and virtualization above 100 rows. The SBOM list page gains a two-row "Compare selected" entry point. JSON/CSV export is client-side.
