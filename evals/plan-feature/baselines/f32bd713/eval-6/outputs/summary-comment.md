## Architecture Summary

The feature adds a vulnerability remediation tracking dashboard with a backend-frontend split:

- **Backend (trustify-backend)**: A new `remediation` domain module following the established `model/ + service/ + endpoints/` pattern. The `RemediationService` computes aggregations from existing `advisory`, `sbom_advisory`, `sbom`, and `package` tables without introducing new database tables. Two new REST endpoints expose summary-by-severity and breakdown-by-product views.
- **Frontend (trustify-ui)**: A new `RemediationDashboardPage` following the existing page directory structure with PatternFly 5 components. Data flows through typed Axios client functions and React Query hooks. The dashboard supports three views: summary cards, progress chart, and a filterable/sortable vulnerability table with server-side pagination for up to 10,000 vulnerabilities.
- **Workflow mode**: direct-to-main (no atomicity constraints identified).
