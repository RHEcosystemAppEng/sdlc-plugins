## Architecture Summary

The feature adds a new REST endpoint `GET /api/v2/sbom/{id}/advisory-summary` to the trustify-backend service. The implementation follows the existing module pattern (model/ + service/ + endpoints/) within the SBOM fundamental module. A new AdvisorySeveritySummary model struct holds deduplicated severity counts. The SbomService gets a new aggregation method that queries the existing sbom_advisory join table joined with the advisory entity, grouping by severity and deduplicating by advisory ID. The endpoint applies a 5-minute cache via tower-http middleware, with cache invalidation triggered by the advisory ingestion pipeline. An optional threshold query parameter supports filtering by minimum severity level.
