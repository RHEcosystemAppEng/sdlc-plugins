## Architecture Summary

The feature adds side-by-side SBOM comparison capability. The backend computes structured diffs between two SBOMs using existing package, advisory, and license entities (no new database tables). The frontend provides a full comparison page built with PatternFly 5 components, with SBOM selectors, six collapsible diff sections, and URL-shareable comparisons. The SBOM list page is enhanced with selection checkboxes and a "Compare selected" action that navigates to the comparison view.
