## Architecture Summary

This feature replaces the `advisory_status` lookup table with a PostgreSQL `advisory_status_enum` enum column directly on the `advisory` table. The migration creates the enum type, adds the column, backfills from the existing FK join, drops the FK column, and drops the lookup table. Entity definitions, service queries, endpoints, and the ingestion pipeline are updated to use the enum column, eliminating join overhead from all advisory queries. Integration tests are updated to verify the new schema. The API response shape remains unchanged.
