## Architecture Summary

The feature adds a read-only comparison capability that computes SBOM diffs on-the-fly without new database tables:

- **Backend:** A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint in the `modules/fundamental/sbom` module. The `SbomService` gains a `compare` method that queries existing `sbom_package`, `sbom_advisory`, and `package_license` entities to compute set differences between two SBOMs. The response contains six diff categories: added packages, removed packages, version changes, new vulnerabilities, resolved vulnerabilities, and license changes.

- **Frontend:** A new `SbomComparePage` at `/sbom/compare` with PatternFly components matching the Figma design. The page uses the existing `useSboms` hook for SBOM selectors and a new `useSbomComparison` React Query hook for data fetching. Six collapsible `ExpandableSection` components display diff results with sortable data tables. The `SbomListPage` gains row selection checkboxes and a "Compare selected" button for navigation. Export (JSON/CSV) is handled client-side.

- **Workflow mode:** `direct-to-main` — each task's PR can merge independently. The backend endpoint is useful standalone (API consumers), and task dependencies enforce correct delivery order.
