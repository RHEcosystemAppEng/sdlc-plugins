## Architecture Summary

The feature adds a structured SBOM comparison capability spanning both repositories:

**Backend (trustify-backend):** A new comparison service in the `fundamental/sbom` module computes diffs between two SBOMs on-the-fly (no new database tables). The service compares package sets, advisory associations, and license mappings, producing a structured diff result. A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint exposes this service via the existing Axum router.

**Frontend (trustify-ui):** A new comparison page at `/sbom/compare` renders the diff result using PatternFly 5 components: dual SBOM selectors, a Compare action button, collapsible ExpandableSection panels for each diff category (Added Packages, Removed Packages, Version Changes, New Vulnerabilities, Resolved Vulnerabilities, License Changes), an Export dropdown for JSON/CSV download, and an EmptyState for initial page load. The SBOM list page gains checkbox selection and a "Compare selected" toolbar action for navigation to the comparison view. URL query parameters make comparisons shareable.

**Workflow mode:** `feature-branch` — the frontend comparison page and backend comparison endpoint are tightly coupled and must land together.

**Epic grouping:** by-sub-feature — Backend comparison service (Tasks 2-3), Frontend comparison UI (Tasks 4-6), Documentation (Task 7).
