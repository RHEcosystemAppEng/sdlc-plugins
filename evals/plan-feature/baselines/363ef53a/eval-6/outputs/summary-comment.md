## Architecture Summary

The backend adds a new `remediation` module following the established `model/ + service/ + endpoints/` pattern. The `RemediationService` computes aggregated vulnerability remediation statistics from existing advisory and SBOM relationship data (no new database tables). Two new REST endpoints expose the aggregation: `/api/v2/remediation/summary` (by severity and status) and `/api/v2/remediation/by-product` (per-product breakdown with pagination).

The frontend adds a new dashboard page at `/remediation` using PatternFly 5 components. The page includes summary cards (Open/In Progress/Resolved counts by severity), a progress chart (30-day remediation trend), and a filterable vulnerability table (filter by severity, product, and status). Data flows through the established API layer pattern: Axios client -> typed API functions -> React Query hooks -> page components.
