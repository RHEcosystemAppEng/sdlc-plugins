## Architecture summary
`ownerGroup` is added to the shared catalog record in the store layer. The shared update helper keeps the stored value when an update omits it and replaces it when an update supplies one. Record IDs do not change. Registration collects and validates the field when a record is created. Both consumers (summary API, downloadable report) read it through the existing store read helpers and show an explicit null or empty value for records stored without one, so missing data is visible rather than hidden. Workflow mode: `direct-to-main`, because no atomicity indicators were found.
