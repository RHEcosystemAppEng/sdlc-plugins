## Architecture Summary

The feature adds a side-by-side SBOM comparison capability:

1. **Backend**: A new `SbomComparisonService` computes structured diffs between two SBOMs by comparing their package sets, advisory associations, and license mappings. The diff is exposed via `GET /api/v2/sbom/compare?left={id1}&right={id2}`. No new database tables are required — diffs are computed on-the-fly from existing entity data.

2. **Frontend**: A new `SbomComparePage` renders the comparison result using PatternFly components (ExpandableSection, Table, Badge, Select, EmptyState). Users can initiate comparisons from the SbomListPage (multi-select + "Compare selected") or via direct URL. Comparisons are URL-shareable via query parameters. Export to JSON/CSV is supported from the client-side comparison data.

3. **Workflow**: Feature-branch mode (`TC-9003` branches in both repos) ensures coordinated delivery — the frontend comparison page requires the new backend endpoint.
