## Architecture Summary
The backend adds a new `remediation` module under `modules/fundamental/` following the existing model/service/endpoints pattern. The service computes aggregation counts from existing vulnerability and SBOM relationship data (no new database tables). Two new endpoints are exposed at `/api/v2/remediation/summary` and `/api/v2/remediation/by-product`. The frontend adds a new dashboard page at `/remediation` using PatternFly 5 components, React Query hooks for data fetching, and a filterable vulnerability table with severity/product/status filters.
