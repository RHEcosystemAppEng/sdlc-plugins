## Architecture Summary

The SBOM comparison feature spans two repositories with a clear backend-first dependency chain:

1. **Backend (trustify-backend):** A new `SbomService::compare()` method computes structured diffs between two SBOMs by querying existing package, advisory, and license entities. The diff is exposed via `GET /api/v2/sbom/compare?left={id1}&right={id2}` returning a `SbomComparisonResult` with six diff categories. No new database tables are needed -- diffs are computed in-memory from existing data.

2. **Frontend (trustify-ui):** TypeScript interfaces mirror the backend response shape. A React Query hook (`useSbomComparison`) manages data fetching. The comparison page uses PatternFly 5 components (Select, ExpandableSection, Badge, Table, EmptyState, Skeleton) per the Figma design. URL query parameters enable shareable comparisons. Client-side export supports JSON and CSV output.

3. **Cross-repo dependency:** Frontend Task 4 explicitly depends on Backend Task 3 for the API contract. The feature-branch workflow ensures coordinated delivery.
