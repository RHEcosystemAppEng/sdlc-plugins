## Architecture Summary

The license compliance report feature adds a new read-only endpoint (`GET /api/v2/sbom/{id}/license-report`) to the existing SBOM module. The implementation follows the established module pattern (model/ + service/ + endpoints/) without introducing new database tables. The service aggregates license data from existing `package_license` and `sbom_package` entities, groups packages by license type, and evaluates compliance against a configurable JSON policy file. The feature supports two use cases: manual compliance review by officers and automated CI/CD compliance gating.
