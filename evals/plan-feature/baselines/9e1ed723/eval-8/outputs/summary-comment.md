### Architecture summary
`ownerGroup` is added once, to the shared catalog record contract in `src/catalog/store.py`. The change is additive and keeps the stored value on update when no new value is supplied. Onboarding (`registration.py`) writes it. The summary API and the downloadable report read it from the shared record, with consistent null/empty handling for records that lack it.
