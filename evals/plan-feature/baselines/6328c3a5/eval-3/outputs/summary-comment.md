## Architecture Summary

The SBOM comparison feature adds a new diffing capability across both repositories:

**Backend (trustify-backend):** A new `SbomComparisonService` computes structured diffs between two SBOMs by comparing their package lists (via `sbom_package` join table), advisory associations (via `sbom_advisory` join table), and license mappings. The service is exposed through a new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint that returns six diff categories: added packages, removed packages, version changes, new vulnerabilities, resolved vulnerabilities, and license changes. No new database tables are required — all diffs are computed on-the-fly from existing entity relationships.

**Frontend (trustify-ui):** A new `SbomComparePage` at `/sbom/compare` renders a header toolbar with two PatternFly `Select` dropdowns for SBOM selection and six collapsible `ExpandableSection` diff sections with data tables. The page supports URL-shareable comparisons via query parameters. The SBOM list page gains row selection checkboxes and a "Compare selected" button for navigation to the comparison view. An export dropdown (non-MVP) allows downloading the diff as JSON or CSV.
