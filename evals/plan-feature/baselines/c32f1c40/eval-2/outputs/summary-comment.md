## Architecture Summary

The implementation plan addresses three MVP requirements for TC-9002 across the trustify-backend repository:

1. **Search performance** (Task 1): A new database migration adds PostgreSQL tsvector columns with GIN indexes and trigger functions to the sbom, advisory, and package tables. This replaces sequential text scans with indexed full-text search lookups.

2. **Search relevance** (Task 2): The SearchService is updated to use `ts_rank()` scoring against the weighted tsvector columns, ordering results by relevance when a search query is provided. Entity definitions are updated to map the new tsvector columns.

3. **Search filtering** (Task 3): The search endpoint gains optional filter query parameters (entity_type, date_from, date_to, severity) that integrate with the existing shared query helpers in `common/src/db/query.rs`. This task is independent of the performance and relevance tasks.
