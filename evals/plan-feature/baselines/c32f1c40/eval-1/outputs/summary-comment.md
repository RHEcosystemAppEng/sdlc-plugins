## Architecture Summary

The feature adds a new `GET /api/v2/sbom/{id}/advisory-summary` endpoint to the trustify-backend service. The implementation follows the established module pattern (model/ + service/ + endpoints/) within the existing `modules/fundamental/src/sbom/` module:

1. **Model layer**: New `AdvisorySeveritySummary` response struct with severity count fields
2. **Service layer**: New aggregation method on `SbomService` that queries the `sbom_advisory` join table, joins with `advisory`, deduplicates by advisory ID, and groups by severity
3. **Endpoint layer**: New route handler with 5-minute tower-http cache and 404 handling for non-existent SBOMs
4. **Cache invalidation**: Advisory ingestion pipeline updated to invalidate cached summaries when new advisories are linked
5. **Threshold filtering**: Optional `?threshold` query parameter for alerting integrations (non-MVP)

No new database tables are required — the implementation uses existing `sbom_advisory` and `advisory` entity tables.
