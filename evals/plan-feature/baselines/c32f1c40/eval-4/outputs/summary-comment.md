The license compliance report feature is implemented as a new sub-module within the existing SBOM domain module, following the established `model/ + service/ + endpoints/` pattern. The implementation consists of:

1. **Data layer**: New response types (`LicenseReport`, `LicenseReportGroup`) in the SBOM model layer, plus a license policy configuration module in the common crate

5. **Documentation**: New content documenting the endpoint and policy configuration
