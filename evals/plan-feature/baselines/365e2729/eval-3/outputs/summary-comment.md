## Architecture summary

The backend computes the diff on-the-fly (no new tables): it loads the package sets (name, version, license) and advisory sets for both SBOMs with a fixed number of queries and diffs them in memory into six categories. `GET /api/v2/sbom/compare?left=&right=` returns this, with 400 for missing params and 404 for an unknown SBOM. The frontend adds a typed client and a React Query hook, and a `/sbom/compare` page that keeps the URL as the single source of truth, so comparisons can be shared. The page is built from the Figma design with PatternFly 5 typeahead Selects, ExpandableSections with colored count badges, and composable Tables (virtualized above 100 rows). It also covers empty, skeleton-loading and error states, and highlights critical new vulnerabilities. The SBOM list page gets multi-select plus a "Compare selected" button.
