## Architecture summary
`ownerGroup` is added once, to the shared record schema in `src/catalog/store.py`. The store's persistence helper owns the "preserve unless a new value is supplied" merge rule and rejects writes that would leave the field empty. All four writers that populate the shared catalog go through that helper:
- registration (onboarding)
- scheduled sync
- fallback import
- `POST /api/catalog/refresh`

The two readers (summary API and downloadable report) show the stored value without change. Workflow mode is **direct-to-main**: there are no atomicity indicators, and the schema change and all of its dependents are in one task.
