## Architecture Summary

The feature adds a structured SBOM comparison capability spanning both repositories:

1. **Backend (trustify-backend):** A new `compare` method on `SbomService` computes on-the-fly diffs between two SBOMs by querying existing package, advisory, and license data. The diff result is exposed via `GET /api/v2/sbom/compare?left={id1}&right={id2}`. No new database tables are introduced.

2. **Frontend (trustify-ui):** A new comparison page at `/sbom/compare` uses PatternFly `Select` dropdowns for SBOM selection and PatternFly `ExpandableSection` components for six diff categories. The SBOM list page gains multi-select checkboxes and a "Compare selected" action. URL query parameters enable shareable comparison links.

3. **Cross-repo dependency:** Frontend tasks depend on backend tasks. The comparison page consumes the new backend endpoint, and the API types/hook match the backend response shape.
