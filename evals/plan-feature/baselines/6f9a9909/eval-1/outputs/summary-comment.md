## Architecture Summary

The implementation adds a new advisory severity aggregation endpoint to the SBOM module. The data flows through three layers:

1. **Model layer**: new `AdvisorySeveritySummary` struct in `modules/fundamental/src/sbom/model/`
2. **Service layer**: new `advisory_summary()` method on `SbomService` that runs a SeaORM aggregation query against the `sbom_advisory` join table, deduplicating by advisory ID and grouping by severity
3. **Endpoint layer**: new `GET /api/v2/sbom/{id}/advisory-summary` handler with 5-minute `tower-http` cache and optional `?threshold` query parameter

Cache invalidation is added to the advisory ingestion pipeline (`modules/ingestor/src/graph/advisory/mod.rs`) to clear stale summaries when new advisories are correlated with SBOMs.
