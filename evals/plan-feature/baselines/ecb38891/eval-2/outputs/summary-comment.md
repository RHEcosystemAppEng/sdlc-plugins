### Architecture Summary

The implementation targets the existing search module in trustify-backend. The approach has three layers:

1. **Infrastructure (Task 1):** Add PostgreSQL GIN indexes on searchable text columns and optimize the SearchService to use `tsvector`/`tsquery` full-text search. A new SeaORM migration creates the indexes. The search endpoint is configured with tower-http caching.

2. **Relevance (Task 2):** Add `ts_rank`-based scoring to search queries and order results by relevance by default. A `sort_by` query parameter allows switching between relevance, name, and date ordering. Results include a `rank` field in the response.

3. **Filtering (Task 3):** Add optional filter query parameters (`entity_type`, `date_from`, `date_to`, `severity`) to the search endpoint. Filters use the shared query builder helpers in `common/src/db/query.rs` and produce AND-combined WHERE clauses.
