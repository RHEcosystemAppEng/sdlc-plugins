### Architecture Summary

The current `advisory_status` lookup table is replaced with a PostgreSQL enum column (`advisory_status_enum`) directly on the `advisory` table. The change flows through four layers:

3. **Service/API layer** -- all advisory queries use `WHERE advisory.status = ?` instead of joining `advisory_status`; API response shape unchanged
4. **Ingestion layer** -- pipeline writes enum values directly without lookup table insert
