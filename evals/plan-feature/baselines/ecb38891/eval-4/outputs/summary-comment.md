## Architecture Summary

The license compliance report is implemented as a new sub-resource of the SBOM module, following the existing model/service/endpoints pattern:

1. Models: LicenseReport, LicenseGroup, and LicensePolicy structs added to the SBOM model layer
2. Policy: Configurable JSON-based license policy file stored in the repository root
3. Service: LicenseReportService aggregates package-license data from existing entities (package_license, sbom_package), walks transitive dependencies, groups by license, and applies policy compliance checks
4. Endpoint: GET /api/v2/sbom/{id}/license-report exposed under the existing SBOM route tree
5. Testing: Integration tests in tests/api/license_report.rs following established patterns
6. Documentation: New content covering endpoint usage, policy configuration, and CI/CD integration

No new database tables are introduced — the service aggregates from existing package-license data.
