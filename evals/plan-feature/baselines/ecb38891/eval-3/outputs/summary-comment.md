## Architecture Summary

The feature adds a side-by-side SBOM comparison capability with two main components:

1. **Backend (trustify-backend)**: A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint that computes a structured diff between two SBOMs on-the-fly (no new database tables). The diff covers six categories: added/removed packages, version changes, new/resolved vulnerabilities, and license changes. The service reuses existing `SbomService`, `PackageService`, and `AdvisoryService` for data loading.

2. **Frontend (trustify-ui)**: A new comparison page at `/sbom/compare` built with PatternFly 5 components following the Figma design. Includes two SBOM selector dropdowns, a Compare button, an Export dropdown, and six collapsible diff sections with data tables. URL query parameters enable shareable comparisons. Virtualized rendering handles large diffs (>100 changed packages).
