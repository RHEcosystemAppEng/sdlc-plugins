## Architecture Summary

The plan addresses three MVP requirements from TC-9002 across the `trustify-backend` repository:

1. **Performance** (Task 1): A new database migration adds GIN indexes on full-text search columns across SBOM, advisory, and package entities. The SearchService is updated to use `to_tsvector`/`to_tsquery` patterns that leverage these indexes instead of LIKE/ILIKE patterns.

2. **Relevance** (Task 2): PostgreSQL `ts_rank` scoring is integrated into the search query pipeline. Results are ordered by descending relevance score, and the score is exposed in the API response for each result item.

3. **Filtering** (Task 3): The search endpoint gains optional query parameters for entity type, severity, license, and date range filtering. Filter logic uses conjunctive (AND) composition via SeaORM's `Condition::all()`, following the patterns established in existing list endpoints.

All tasks follow the `direct-to-main` workflow mode — each can be merged independently without breaking `main`.
