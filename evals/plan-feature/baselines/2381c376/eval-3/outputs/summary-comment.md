## Architecture Summary

The feature adds a structured SBOM comparison capability spanning both the backend REST API and the frontend React UI:

**Backend (trustify-backend):**
- New model structs in `modules/fundamental/src/sbom/model/comparison.rs` define the diff result shape (six categories: added/removed packages, version changes, new/resolved vulnerabilities, license changes)
- New service in `modules/fundamental/src/sbom/service/comparison.rs` computes the diff on-the-fly from existing package, advisory, and license data (no new database tables)
- New endpoint `GET /api/v2/sbom/compare?left={id1}&right={id2}` in `modules/fundamental/src/sbom/endpoints/compare.rs` exposes the comparison as a REST API

**Frontend (trustify-ui):**
- API layer: TypeScript interfaces matching the backend response, Axios client function, and React Query hook for data fetching
- Comparison page at `/sbom/compare` with PatternFly 5 components: Select dropdowns for SBOM selection, ExpandableSection for each diff category with Badge counts and composable Tables, EmptyState for initial load, Skeleton placeholders for loading
- SBOM list page extended with row selection checkboxes and "Compare selected" button that navigates to the comparison view
- URL-shareable comparisons via query parameters

**Workflow mode: feature-branch** — the frontend comparison page cannot function without the backend endpoint, so all changes land on the `TC-9003` feature branch before merging to main.
