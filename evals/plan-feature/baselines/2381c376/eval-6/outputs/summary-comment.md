## Architecture Summary

The feature adds a vulnerability remediation tracking dashboard that provides portfolio-wide visibility into remediation progress.

**Backend (trustify-backend):** A new `remediation` module following the established `model/ + service/ + endpoints/` pattern. The service layer aggregates remediation data from existing advisory, SBOM, and package entity tables without creating new database tables. Two new REST endpoints expose the aggregated data: `/api/v2/remediation/summary` (severity x status matrix) and `/api/v2/remediation/by-product` (per-product breakdown with pagination).

**Frontend (trustify-ui):** A new RemediationDashboardPage at `/remediation` with three main components: summary cards (Open/In Progress/Resolved counts), a 30-day progress chart, and a filterable vulnerability table. The API layer follows the established Axios client + React Query hooks pattern. Filters support severity, product, and status dimensions.
