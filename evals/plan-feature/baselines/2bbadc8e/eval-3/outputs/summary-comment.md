## Architecture Summary

The SBOM comparison feature adds a structured diff capability spanning both repositories:

1. **Backend** — A new `SbomService::compare()` method computes a six-category diff (added packages, removed packages, version changes, new vulnerabilities, resolved vulnerabilities, license changes) between two SBOMs using set-based operations on existing data. The diff is exposed via `GET /api/v2/sbom/compare?left={id1}&right={id2}`.

2. **Frontend** — A new page at `/sbom/compare` with a header toolbar (SBOM selectors, Compare button) and collapsible `ExpandableSection` components for each diff category. The page uses React Query for data fetching, PatternFly 5 components throughout, and supports URL-shareable comparisons via query parameters. A non-MVP export dropdown enables JSON/CSV downloads for compliance documentation.
