## Architecture Summary

This feature replaces the `advisory_status` lookup table with a PostgreSQL enum column (`advisory_status_enum`) directly on the `advisory` table. The change eliminates a join on every advisory query, reducing p95 latency by ~40ms on the advisory list endpoint. The implementation spans the database migration layer (SeaORM migrations), entity definitions, advisory service/endpoint query logic, and the ingestion pipeline. The public API response shape is unchanged -- status remains a string value.

**Workflow mode:** `feature-branch` -- all changes are developed on the `TC-9005` branch and merged atomically to `main` via a merge PR, because the migration and code changes are interdependent (merging either side alone would break the application).
