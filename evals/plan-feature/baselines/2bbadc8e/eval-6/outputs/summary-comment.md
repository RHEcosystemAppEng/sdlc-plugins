## Architecture Summary

The feature adds a vulnerability remediation tracking dashboard composed of:

1. **Backend aggregation layer** (trustify-backend): A new `remediation` module under `modules/fundamental/` following the established model/service/endpoints pattern. Two new GET endpoints aggregate vulnerability data from existing entity tables (no new database tables):
   - `GET /api/v2/remediation/summary` — severity x status count matrix
   - `GET /api/v2/remediation/by-product` — per-product breakdown with pagination

2. **Frontend dashboard** (trustify-ui): A new `RemediationDashboardPage` at `/remediation` with summary cards, a 30-day trend progress chart, and a filterable vulnerability table. Uses React Query hooks for data fetching and PatternFly 5 components for UI.
