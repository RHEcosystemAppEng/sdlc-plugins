## Architecture Summary

The license compliance report feature adds a new `GET /api/v2/sbom/{id}/license-report` endpoint to the trustify-backend service. The implementation follows the established module pattern (model/ + service/ + endpoints/):

1. **Model layer** (Task 1): `LicenseReport` and `LicenseGroup` structs in the sbom module, plus a `LicensePolicy` configuration struct in common/
2. **Service layer** (Task 2): `LicenseReportService` that aggregates package-license data from existing SeaORM entities, walks the transitive dependency tree, and checks compliance against the policy
3. **Endpoint layer** (Task 3): Axum handler registered at `/api/v2/sbom/{id}/license-report` following existing endpoint patterns
4. **Test layer** (Task 4): Integration tests in `tests/api/license_report.rs` following existing test patterns
5. **Documentation** (Task 5): New content documenting the endpoint and policy configuration

No new database tables are introduced. All data is aggregated from existing entities: `package`, `sbom_package`, and `package_license`.
