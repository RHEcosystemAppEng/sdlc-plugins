## Architecture Summary

The feature adds a side-by-side SBOM comparison capability across two repositories:

1. **Backend (trustify-backend):** A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint computes a structured diff between two SBOMs on-the-fly from existing package, advisory, and license data. No new database tables are needed. The diff includes six categories: added packages, removed packages, version changes, new vulnerabilities, resolved vulnerabilities, and license changes. The service is built following the existing module pattern (model/ + service/ + endpoints/).

2. **Frontend (trustify-ui):** A new comparison page at `/sbom/compare` renders the diff using PatternFly components (Select for SBOM selection, ExpandableSection for diff categories, composable Table for data display, Badge for counts, EmptyState for initial state, Skeleton for loading). The page supports URL-shareable comparisons via query parameters. The SBOM list page is enhanced with checkbox selection and a "Compare selected" button as the primary entry point.

3. **Documentation:** New content documenting the comparison endpoint and the comparison UI workflow.
