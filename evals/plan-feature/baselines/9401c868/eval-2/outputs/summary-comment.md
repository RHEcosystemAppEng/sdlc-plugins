## Architecture Summary

The implementation improves the existing `modules/search/` module in trustify-backend across three dimensions:

1. **Performance** (Task 1): A new database migration adds GIN indexes on full-text search columns. The `SearchService` in `modules/search/src/service/mod.rs` and the shared query builder in `common/src/db/query.rs` are optimized to generate index-aware queries.

2. **Relevance** (Task 2): PostgreSQL `ts_rank` ranking is added to the `SearchService` to order results by text match quality. The search endpoint in `modules/search/src/endpoints/mod.rs` propagates the ranked ordering.

3. **Filtering** (Task 3): The search endpoint adds optional query parameters (`entity_type`, `severity`, `license`) for narrowing results. Filter logic extends the shared query builder helpers.

All tasks include integration test updates in `tests/api/search.rs`.
