# Repository Impact Map — TC-9001: Add advisory severity aggregation endpoint

## trustify-backend

### Changes

- Add `SeveritySummary` response model struct with fields: `critical`, `high`, `medium`, `low`, `total`
- Add `SbomService::get_advisory_severity_summary` aggregation method that queries the `sbom_advisory` join table, deduplicates by advisory ID, and groups counts by severity level
- Add `GET /api/v2/sbom/{id}/advisory-summary` endpoint with 5-minute response caching via `tower-http` middleware
- Support optional `?threshold` query parameter to filter severity counts above a specified level
- Return 404 when SBOM ID does not exist (consistent with existing SBOM endpoints)
- Add cache invalidation in the advisory ingestion pipeline to clear cached advisory-summary responses when new advisories are linked to an SBOM
- Add integration tests for the advisory-summary endpoint covering response format, 404 handling, deduplication, threshold filtering, and caching behavior
