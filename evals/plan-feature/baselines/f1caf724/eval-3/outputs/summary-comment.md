## Architecture Summary

The feature adds a side-by-side SBOM comparison capability spanning both repositories:

**Backend (trustify-backend):** A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint computes a structured diff between two SBOMs on-the-fly (no new database tables). The diff engine uses existing `SbomService`, `PackageService`, and `AdvisoryService` to fetch data for each SBOM, then computes six diff categories: added packages, removed packages, version changes, new vulnerabilities, resolved vulnerabilities, and license changes. The comparison model and service follow the established `model/ + service/ + endpoints/` module pattern.

**Frontend (trustify-ui):** A new comparison page at `/sbom/compare` renders the diff using PatternFly `ExpandableSection` components with count badges and data tables per the Figma design. The SBOM list page gains checkbox multi-selection with a "Compare selected" action that navigates to the comparison view. URL query parameters (`left`, `right`) enable shareable comparison links. The API layer adds TypeScript types and a `useSbomComparison` React Query hook.

**Cross-repo dependency:** The frontend comparison page depends on the backend comparison endpoint. Task ordering enforces backend tasks (2, 3) before dependent frontend tasks (4, 5, 6).
