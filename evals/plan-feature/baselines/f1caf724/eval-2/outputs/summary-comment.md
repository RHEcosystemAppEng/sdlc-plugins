## Architecture Summary

The implementation plan addresses three MVP requirements from TC-9002 through incremental improvements to the existing search module in `trustify-backend`:

1. **Performance (Task 1):** A new SeaORM migration adds GIN indexes on text-searchable columns across SBOM, advisory, and package entities. This is the foundation task that both subsequent tasks depend on, as full-text search ranking and filtered queries benefit from indexed columns.

2. **Relevance (Task 2):** The SearchService is refactored to use PostgreSQL's native full-text search capabilities (tsvector/tsquery with ts_rank) instead of basic text matching. Results are sorted by relevance score by default, with title/name fields weighted higher than description fields.

3. **Filtering (Task 3):** The search endpoint gains optional filter query parameters for entity type and date range, following the established query builder patterns in `common/src/db/query.rs`. All filters are optional and backward-compatible.
