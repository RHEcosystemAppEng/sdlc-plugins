## Architecture Summary

This feature replaces the `advisory_status` lookup table with a PostgreSQL enum column (`advisory_status_enum`) directly on the `advisory` table. The migration creates the enum type with four values (New, Analyzing, Fixed, Rejected), backfills existing rows, and drops the lookup table and FK column atomically. SeaORM entity definitions, advisory service queries, endpoint handlers, and the ingestion pipeline are all updated to use the enum column directly, eliminating the join overhead that added ~40ms to the advisory list endpoint p95 latency.
