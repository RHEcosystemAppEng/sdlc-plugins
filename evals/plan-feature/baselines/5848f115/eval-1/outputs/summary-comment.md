#### Architecture Summary

The feature adds a new `GET /api/v2/sbom/{id}/advisory-summary` endpoint to the trustify-backend service. It follows the existing module pattern (`model/ + service/ + endpoints/`):

- **Model layer**: new `AdvisorySeveritySummary` struct in `modules/fundamental/src/sbom/model/`
- **Service layer**: aggregation query in `SbomService` using the existing `sbom_advisory` join table and `advisory` entity, deduplicating by advisory ID
- **Endpoint layer**: Axum handler in `modules/fundamental/src/sbom/endpoints/` with 5-minute `tower-http` cache
- **Cache invalidation**: in the advisory ingestion pipeline (`modules/ingestor/src/graph/advisory/`)
- **Non-MVP threshold filtering**: optional `?threshold` query parameter for alerting integrations
- **Testing**: integration tests in `tests/api/`, plus cross-cutting smoke tests and performance benchmarks

No new database tables are required — the feature uses existing `sbom_advisory` relationship tables.
