## Architecture Summary

The feature adds a side-by-side SBOM comparison capability with two main components:

1. **Backend**: A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint that computes a structured diff between two SBOMs on-the-fly. The diff covers six categories: added/removed packages, version changes, new/resolved vulnerabilities, and license changes. No new database tables are required — the diff is computed from existing entity data (sbom_package, sbom_advisory, package_license join tables).

2. **Frontend**: A new comparison page at `/sbom/compare` following Figma mockups with PatternFly 5 components. The page includes SBOM selectors, collapsible diff sections with count badges, critical vulnerability highlighting, and URL-shareable comparisons. An entry point is added to the SBOM list page via "Compare selected" action.
