## Architecture Summary

The license compliance report feature adds a new `GET /api/v2/sbom/{id}/license-report` endpoint that returns packages grouped by license with compliance flags. The implementation follows the existing module pattern (model + service + endpoint):

1. **Model layer**: New `LicenseReport`, `LicenseGroup`, and `CompliancePolicy` types in the SBOM model module
2. **Policy configuration**: Configurable license policy loaded from a JSON file (allowed/denied SPDX identifiers)
3. **Service layer**: `LicenseReportService` aggregates license data from existing `package_license` and `sbom_package` tables, walks transitive dependencies, and applies compliance rules
4. **Endpoint layer**: GET handler registered under the SBOM endpoint module
5. **No new database tables** — the feature aggregates from existing package-license data

Performance target: p95 < 500ms for SBOMs with up to 1000 packages.
