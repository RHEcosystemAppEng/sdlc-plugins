## Architecture Summary

The feature adds a structured SBOM comparison capability across two repositories:

**Backend (trustify-backend):** A new `SbomComparisonResult` model captures six diff categories (added/removed packages, version changes, new/resolved vulnerabilities, license changes). A `compare` method on `SbomService` loads both SBOMs' packages and advisories, then computes the diff using efficient set operations. A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint exposes the comparison via REST. No new database tables are needed — diffs are computed on-the-fly from existing entity relationships.

**Frontend (trustify-ui):** TypeScript interfaces mirror the backend response shape. A React Query hook (`useSbomComparison`) manages data fetching with automatic cache key management. The `SbomComparisonPage` renders a header toolbar with PatternFly Select dropdowns for SBOM selection and six `ExpandableSection` components, each containing a data table with category-specific columns. The page supports URL-shareable comparisons and integrates with the SBOM list page via a "Compare selected" action.
