### Architecture Summary

The plan targets the `modules/search/` module in trustify-backend, which provides full-text search across SBOMs, advisories, and packages via `GET /api/v2/search`. Changes span four areas:

1. **Database layer** — New migration adds GIN and B-tree indexes on search-relevant columns to improve query performance.
2. **Service layer** — SearchService query optimization (full-text search operators, early result limiting) and relevance scoring via PostgreSQL `ts_rank`.
3. **API layer** — Search endpoint gains optional filter query parameters (entity_type, date range, severity) and a sort parameter (relevance/date), all backward-compatible.
4. **Test layer** — Comprehensive integration tests covering filters, ranking, and backward compatibility.
