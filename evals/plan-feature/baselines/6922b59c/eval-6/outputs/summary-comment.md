## Architecture Summary

The feature adds a remediation tracking dashboard with a clear backend/frontend split:

- **Backend (trustify-backend):** A new `remediation` domain module under `modules/fundamental/` following the established model/service/endpoints pattern. The service computes aggregations from existing `sbom`, `advisory`, and `sbom_advisory` entity relationships without creating new database tables. Two new REST endpoints serve the summary and per-product breakdown data.

- **Frontend (trustify-ui):** A new `RemediationDashboardPage` under `src/pages/` following the standard page directory structure. The page uses PatternFly 5 components for UI, React Query hooks for data fetching, and integrates the reusable `FilterToolbar` and `SeverityBadge` components for the vulnerability table.
