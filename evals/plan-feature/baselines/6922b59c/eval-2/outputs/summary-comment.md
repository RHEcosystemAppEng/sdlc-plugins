## Architecture Summary

The plan addresses three MVP requirements from TC-9002 across the `trustify-backend` search module:

1. **Performance** (Task 1): Adds GIN database indexes on searchable text columns (name, description) across sbom, advisory, and package entities, and optimizes SearchService to use PostgreSQL full-text search (tsvector/tsquery) instead of LIKE patterns.

2. **Relevance** (Task 2): Implements relevance scoring using PostgreSQL `ts_rank()` functions, extending the `PaginatedResults` response wrapper to include per-item scores, and adding a `sort_by` parameter to the search endpoint.

3. **Filtering** (Task 3): Adds filter query parameters (entity_type, severity, date_range) to the GET /api/v2/search endpoint, using the shared query builder helpers for filter predicate construction.

All changes follow the existing module pattern (model/ + service/ + endpoints/), reuse shared utilities from `common/`, and maintain backward compatibility with the existing search API.
