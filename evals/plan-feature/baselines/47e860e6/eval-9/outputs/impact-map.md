```
    - Tracker client must tell "authenticated, genuinely no matches" apart from "empty because the request was unauthenticated or under-privileged". An empty search result whose authentication cannot be proven must raise or exit non-zero, not return [].

    - Tests for the client, the gate, and the wrapper must cover the fail-closed degraded/empty path as well as the ready / not-ready / no-linked-issue paths.
```
