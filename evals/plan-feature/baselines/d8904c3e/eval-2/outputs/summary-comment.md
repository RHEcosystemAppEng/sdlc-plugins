## Architecture Summary

The plan enhances the existing search module in trustify-backend across three dimensions:

1. **Performance (Task 1):** A new database migration adds GIN indexes for PostgreSQL full-text search on the `sbom`, `advisory`, and `package` tables. This provides the index infrastructure needed by Tasks 2 and 3.

2. **Relevance (Task 2):** The SearchService is enhanced to use PostgreSQL's `ts_rank` for relevance scoring, ordering results by match quality rather than returning unranked results.

3. **Filtering (Task 3):** The search endpoint gains optional query parameters (`type`, `severity`, `after`, `before`) that allow users to narrow results. Filters use the existing query builder infrastructure in `common/src/db/query.rs`.

All changes are additive — the existing `GET /api/v2/search` API contract is preserved. New parameters are optional and the response shape (`PaginatedResults<T>`) remains unchanged.
