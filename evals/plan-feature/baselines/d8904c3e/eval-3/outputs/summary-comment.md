## Architecture Summary

The SBOM comparison feature adds a structured diff capability across two layers:

**Backend (trustify-backend):** A new comparison service in the existing `sbom` module computes a diff between two SBOMs by querying the existing package, advisory, and license data. The service produces a `SbomComparisonResult` with six diff categories (added/removed packages, version changes, new/resolved vulnerabilities, license changes). A new `GET /api/v2/sbom/compare?left={id1}&right={id2}` endpoint exposes this service. No new database tables are needed -- diffs are computed on-the-fly from existing entity relationships.

**Frontend (trustify-ui):** A new `SbomComparePage` renders the comparison result using PatternFly ExpandableSection components for each diff category, with sortable Tables and color-coded count Badges. The page integrates with the existing SBOM list page via checkbox selection and a "Compare selected" action button. URL query parameters enable shareable comparison links.

**Workflow mode:** feature-branch (TC-9003) -- the frontend comparison page requires the backend endpoint to function, making coordinated delivery necessary.
