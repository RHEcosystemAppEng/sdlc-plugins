## Architecture Summary

The license compliance report feature adds a new `GET /api/v2/sbom/{id}/license-report`
endpoint to the existing SBOM module. The implementation follows the established
`model/ + service/ + endpoints/` module pattern:

- **Model layer** (Task 1): defines response types (`LicenseReport`, `LicenseGroup`)
  and policy configuration types (`LicensePolicy`, `PolicyRule`)
- **Service layer** (Task 2): implements the report generation logic -- walks the
  SBOM dependency tree via existing `sbom_package` and `package_license` entities,
  groups packages by license, and evaluates compliance against the policy
- **Endpoint layer** (Task 3): exposes the service via the REST API with proper
  error handling and route registration
- **Testing** (Task 4): integration tests using the established PostgreSQL test
  database pattern
- **Documentation** (Task 5): new content documenting the endpoint and policy
  configuration for compliance officers
