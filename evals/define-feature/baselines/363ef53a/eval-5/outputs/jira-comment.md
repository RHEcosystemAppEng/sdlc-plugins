# Jira Comment

This comment is posted to the newly created Feature issue via `addCommentToJiraIssue`.

## Call Parameters

```
addCommentToJiraIssue(
  cloudId="2b9e35e3-6bd3-4cec-b838-f4249ee02432",
  issueIdOrKey="<created-issue-key>",
  comment=<comment-body-below>,
  contentFormat="adf"
)
```
