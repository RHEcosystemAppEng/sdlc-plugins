## API Call Details

**Method:** addCommentToJiraIssue (MCP) or `POST /rest/api/3/issue/{issueKey}/comment` (REST API)

**Parameters:**

- **cloudId:** 2b9e35e3-6bd3-4cec-b838-f4249ee02432
- **issueIdOrKey:** (created issue key, e.g., TC-XXX)
