## Root Cause

The plan-feature skill's convention conformance analysis extracts CONVENTIONS.md
section headings using `line[3:]`, which preserves trailing whitespace from the
heading line. When a heading is written as `## Migration Patterns  ` (with trailing
spaces), the extracted section name becomes `"Migration Patterns  "` instead of
`"Migration Patterns"`. The downstream convention-matching step uses exact string
comparison (`if convention_name in discovered_conventions`), which fails because the
lookup key `"Migration Patterns"` does not match the stored key
`"Migration Patterns  "`. The convention is silently skipped with no warning.

## Affected Files

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- Convention conformance
  analysis section: heading extraction at `line[3:]` does not strip trailing
  whitespace.
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- Convention-aware task
  enrichment section: exact-match lookup `if convention_name in discovered_conventions`
  fails when keys have trailing whitespace.

## Suggested Approach

1. **Primary fix**: Apply `.strip()` to the heading extraction:
   change `section_name = line[3:]` to `section_name = line[3:].strip()`.
   This normalizes heading names regardless of trailing whitespace in the source file.

2. **Secondary improvement** (optional): Add a warning log when a convention name
   referenced during task enrichment is not found in the discovered conventions
   dictionary. This would surface similar matching failures in the future rather
   than silently dropping conventions.

## Reproducer Strategy

Create a test fixture `CONVENTIONS.md` that includes a heading with trailing
whitespace (e.g., `## Migration Patterns  ` with two trailing spaces). Run the
plan-feature convention conformance analysis against this fixture. Assert that the
convention is correctly matched and included in the generated task's Implementation
Notes -- the assertion should verify the output contains the expected convention
reference string (e.g., `Per CONVENTIONS.md Migration Patterns:`).

Before the fix, this test should fail (convention silently dropped). After the fix,
it should pass (convention correctly included).
