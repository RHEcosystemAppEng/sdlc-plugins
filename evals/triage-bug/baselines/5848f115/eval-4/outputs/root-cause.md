# Step 4 -- Root Cause Analysis: ACME-510

## Root Cause Determination

### What is broken

The `/api/v2/advisories` endpoint does not emit `X-Total-Count` and `Link` pagination headers when date range filter parameters (`publishedAfter`, `publishedBefore`) are supplied. The response body contains the correct filtered advisories, but clients relying on pagination headers cannot determine the total number of results or navigate pages.

### Why it is broken

The date range filtering code path bypasses the pagination header generation logic. When no filters are applied, the handler follows the standard pagination flow: it executes a count query to determine total matching records, then sets the `X-Total-Count` and `Link` headers before returning the paginated results. However, when date range filters are present, the handler constructs a filtered query that returns results directly without invoking the count query or the pagination header utility. This is likely because the filtered query path was added as a separate branch that returns early, missing the shared pagination logic that the unfiltered path uses.

### Where it is broken

- **Primary defect**: The advisories endpoint handler -- specifically the filtered query branch that handles `publishedAfter`/`publishedBefore` parameters. This branch returns the query results without calling the pagination header utility.
- **Pagination utility**: The shared function/middleware that computes and sets `X-Total-Count` and `Link` headers is functional but simply not invoked from the filtered path.

### How to verify the fix

A reproducer test should:
1. Call `GET /api/v2/advisories?publishedAfter=2025-01-01&publishedBefore=2025-06-30&limit=10` against a test dataset with more than 10 matching advisories.
2. Assert that the response includes the `X-Total-Count` header with the correct total count of matching advisories.
3. Assert that the response includes a `Link` header with `rel="next"` when more pages exist.
4. Verify that the response body still contains the correct filtered advisories (no regression on data correctness).
