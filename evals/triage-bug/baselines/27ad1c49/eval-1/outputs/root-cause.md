## Root Cause

The plan-feature skill's convention conformance analysis extracts CONVENTIONS.md section
headings using `line[3:]`, which preserves any trailing whitespace present on the heading
line. When a CONVENTIONS.md heading contains trailing spaces (e.g., `## Migration Patterns  `),
the extracted section name becomes `"Migration Patterns  "` (with trailing spaces). The
subsequent convention-matching step performs an exact key lookup against clean convention
names (without trailing whitespace), so the match fails silently. No warning or error is
emitted, and the convention is omitted from the generated task description.

## Affected Files

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`
  - **Convention heading extraction**: `section_name = line[3:]` -- does not call `.strip()`
    on the extracted heading text
  - **Convention-aware task enrichment**: `if convention_name in discovered_conventions` --
    exact-match lookup fails when keys contain trailing whitespace

## Suggested Approach

Apply `.strip()` (or `.rstrip()`) to the extracted heading text at the extraction point:

```python
section_name = line[3:].strip()
```

This normalizes the dictionary key so that downstream exact-match lookups succeed regardless
of trailing whitespace in the source file. The fix is a single-line change at the extraction
site.

## Reproducer Strategy

1. Create a CONVENTIONS.md fixture with trailing whitespace on one or more heading lines
   (e.g., `## Migration Patterns  ` with two trailing spaces).
2. Run the plan-feature convention conformance analysis against this fixture.
3. Assert that the convention IS matched and included in the generated task's Implementation
   Notes -- before the fix, this assertion fails (convention silently dropped); after the
   fix, it passes.

An eval-level test using the existing `evals/plan-feature/` structure is the appropriate
test pattern. The fixture file `evals/plan-feature/files/conventions-mock.md` should be
augmented (or a new fixture created) to include trailing whitespace on headings.
