## Root Cause

The plan-feature skill's convention conformance analysis extracts `CONVENTIONS.md`
section headings using `line[3:]`, which captures everything after the `## ` prefix
**without stripping trailing whitespace**. When a heading line contains trailing
spaces (e.g., `## Migration Patterns  `), the extracted section name becomes
`"Migration Patterns  "` instead of `"Migration Patterns"`.

The subsequent convention-aware task enrichment performs an **exact-match lookup**
against the extracted section names. Since the lookup key does not include trailing
whitespace, the match fails silently. No warning, error, or fallback behavior is
triggered -- the convention is simply omitted from the generated task description.

## Affected Files

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- convention conformance
  analysis section, specifically the heading extraction logic:
  ```python
  section_name = line[3:]  # Missing .strip() or .rstrip()
  ```
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- convention-aware task
  enrichment section, specifically the exact-match lookup:
  ```python
  if convention_name in discovered_conventions:
  ```

## Suggested Approach

1. **Primary fix**: Add `.strip()` to the heading extraction to normalize section
   names, e.g., `section_name = line[3:].strip()`. This ensures trailing (and
   leading) whitespace in `CONVENTIONS.md` headings does not affect matching.

2. **Defensive enhancement** (optional): Add a warning log when a convention name
   from the feature analysis does not match any discovered convention. This would
   surface silent failures in future edge cases beyond whitespace (e.g., typos,
   case mismatches).

## Reproducer Strategy

A reproducer test should:

1. Create a `CONVENTIONS.md` fixture with trailing whitespace on at least one
   section heading (e.g., `## Migration Patterns  ` with trailing spaces).
2. Run the convention extraction logic against this fixture.
3. Assert that the extracted section name is `"Migration Patterns"` (without
   trailing whitespace).
4. Assert that the convention-aware task enrichment successfully matches the
   convention and includes it in the generated Implementation Notes.

The test should fail before the fix (section name retains trailing whitespace,
match fails) and pass after the fix (section name is stripped, match succeeds).
