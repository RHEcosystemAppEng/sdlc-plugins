### Root Cause

**What is broken:** The plan-feature skill's convention lookup does not match `CONVENTIONS.md` section headings that end with trailing whitespace. It then skips the matching convention when it enriches task Implementation Notes.

**Why it is broken:** The heading parser takes the section name with `section_name = line[3:]`, which keeps everything after `"## "`, including trailing spaces or tabs. A heading such as `## Migration Patterns  ` is stored under the key `"Migration Patterns  "`. Task enrichment then does an exact-match lookup (`if convention_name in discovered_conventions`) with `"Migration Patterns"`. The lookup fails, and because there is no warning on a miss, the convention is dropped without notice.

**Where it is broken:**
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`, convention conformance analysis (heading extraction `line[3:]`). This is the primary defect.
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`, convention-aware task enrichment (exact-match lookup with no warning when a convention is not found). This hides the defect.

### Affected Files
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`: convention lookup heading parsing and convention-aware task enrichment
- `evals/plan-feature/files/conventions-mock.md`: existing fixture with no trailing-whitespace coverage (test gap)

### Suggested Approach
- Normalize heading text when extracting it: strip leading and trailing whitespace from the section name, including `\r` from CRLF files, before storing it as a key.
- Optionally normalize the lookup key the same way, so both sides of the comparison are canonical.
- Optionally make a declared but unmatched convention produce a visible warning instead of failing silently.

### Reproducer Strategy
- Add a plan-feature eval fixture whose `CONVENTIONS.md` contains `## Migration Patterns  ` (two trailing spaces) followed by `Add Index::create() for all FK columns.`
- Run plan-feature on a feature that needs an FK migration and assert that the generated task's Implementation Notes contain `Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns.`
- Before the fix the assertion fails (the convention is missing). After the fix it passes.
- Also assert that the section name in the note has no trailing whitespace (`§Migration Patterns:` and not `§Migration Patterns  :`).

### Persistence Impact
None. The convention map is computed in memory each time plan-feature runs, so no data migration is required.
