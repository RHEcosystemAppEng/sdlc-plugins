## Root Cause

plan-feature's convention conformance analysis takes `CONVENTIONS.md` section names with
`line[3:]` and does not strip whitespace. A heading such as `## Migration Patterns  ` is stored
under the key `"Migration Patterns  "`, trailing spaces included. Convention-aware task enrichment
then checks `if convention_name in discovered_conventions` with the clean name
`"Migration Patterns"`. The exact match fails, and the `if` has no warning or `else` branch, so
the convention is silently left out of the generated task's Implementation Notes.

- **What is broken:** convention headings with trailing whitespace are never matched during task enrichment.
- **Why:** the extracted heading text is not normalized (no `strip()`), and the enrichment lookup
  uses exact string membership.
- **Where:** `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`, in the heading-extraction logic of
  the convention conformance analysis and the name lookup in convention-aware task enrichment.
- **Scope:** any `##` heading with trailing spaces, tabs, or a CRLF `\r` is affected the same way.
  This is not specific to `Migration Patterns`.

## Affected Files

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`
  - Convention conformance analysis: `section_name = line[3:]` (defect: no whitespace normalization)
  - Convention-aware task enrichment: `if convention_name in discovered_conventions:` (match fails silently)
- `evals/plan-feature/files/conventions-mock.md`: the existing fixture has no trailing whitespace,
  so evals do not cover this case

## Suggested Approach

1. Normalize extracted heading names by stripping leading and trailing whitespace (including `\t`
   and `\r`) before using them as keys in the conventions map.
2. Apply the same normalization to the lookup name in task enrichment, so the comparison is
   whitespace-insensitive on both sides.
3. Replace the silent drop with a visible warning when an expected convention cannot be matched.
   Future mismatches will then show up instead of being lost.

No data migration is needed. The conventions map is computed on each plan-feature run and is
never persisted to a database.

## Reproducer Strategy

Add a plan-feature eval fixture whose `CONVENTIONS.md` contains:

```
## Migration Patterns␠␠
Add Index::create() for all FK columns.
```

(␠ = a literal trailing space.) Run plan-feature on a feature that needs a database migration with
foreign keys. Assert that the generated task's Implementation Notes contain
`Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns`.

- **Before the fix:** the assertion fails, because the convention is absent (matches the Actual Result).
- **After the fix:** the assertion passes (matches the Expected Result).

The existing fixture with clean headings must still produce the same convention references, as a
no-regression check.
