## 4.5.2 – Extract version from description

Environment / Version section content:

> Not sure which version — using whatever is deployed on staging.

Pattern checks:

| Pattern | Example | Found in section? |
|---|---|---|
| Explicit version number | `0.9.0`, `2.1.1` | No. The text has no digits at all. |
| Product-prefixed version | `RHTPA 2.1.0` | No |
| Version keyword + number | `version 1.2.3` | No. The word "version" appears ("which version"), but no number follows it. |

The content is vague and contains no version identifier:
- "Not sure which version": the reporter says outright that the version is unknown.
- "whatever is deployed on staging": this names an environment, not a release. What runs on
  staging changes over time and cannot be mapped to a Jira version without outside data.
  Guessing a version from this would break the "Do not guess" rule.

**Result: no version can be extracted.** Per 4.5.2, skip 4.5.3 (discover Jira versions),
4.5.4 (match) and 4.5.5 (confirm/set) and go straight to **4.5.6 (gap flagging)**.
