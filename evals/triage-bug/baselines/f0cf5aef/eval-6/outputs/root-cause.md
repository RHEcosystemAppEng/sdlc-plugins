# Step 4 -- Root Cause Analysis: ACME-500

## Root Cause Determination

### What is broken

The plan-feature skill's convention conformance analysis silently drops conventions from `CONVENTIONS.md` when heading lines contain trailing whitespace. The generated task description omits conventions that should have been included, with no warning or error to alert the user.

### Why it is broken

The heading extraction logic uses `line[3:]` to extract the section name from `## ` headings, but does not strip trailing whitespace from the result. When a heading like `## Migration Patterns  ` is parsed, the extracted key becomes `"Migration Patterns  "` (with trailing spaces). The subsequent convention lookup performs an exact string match against the canonical convention name `"Migration Patterns"` (without trailing spaces), which fails. Because the lookup failure is silent (no warning is logged), the convention is dropped without any indication to the user.

### Where it is broken

- **Primary defect**: Convention heading extraction in `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- the `line[3:]` expression does not call `.strip()` to normalize the extracted heading text.
- **Silent failure**: Convention-aware task enrichment in the same file -- the `if convention_name in discovered_conventions` lookup silently skips unmatched conventions without logging a warning.

### How to verify the fix

A reproducer test should:
1. Create a `CONVENTIONS.md` with a heading that has trailing whitespace (e.g., `## Migration Patterns  ` with two trailing spaces).
2. Define a convention body under that heading (e.g., `Add Index::create() for all FK columns.`).
3. Run the plan-feature convention conformance analysis against a feature that should trigger that convention.
4. Assert that the generated task's Implementation Notes include the convention reference: `Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns.`
5. Verify that the convention is matched regardless of trailing whitespace on the heading.
