# Step 4 – Root Cause Analysis: ACME-500

## Root Cause

**What is broken**: The convention conformance analysis in the `plan-feature` skill silently
discards any CONVENTIONS.md section whose heading line contains trailing whitespace. The
generated task's Implementation Notes omit the affected convention with no warning.

**Why it is broken**: The heading extraction step uses `line[3:]` to parse the text after
`"## "`. This slice operation preserves all trailing characters — including trailing spaces
and carriage returns — that may appear between the visible heading text and the line
terminator. The extracted section name (e.g., `"Migration Patterns  "`) is stored as a
dictionary key with the extra whitespace embedded. Later, the task enrichment step performs
an exact-string lookup using the clean expected name (`"Migration Patterns"`). Because the
stored key and the lookup key differ by trailing spaces, the lookup returns `False` and the
convention is silently skipped.

**Where it is broken**:

| Location | File | Symbol / Code |
|----------|------|---------------|
| Primary — heading extraction | `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` | `section_name = line[3:]` in the convention conformance loop |
| Secondary — match failure | `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` | `if convention_name in discovered_conventions:` in the task enrichment step |

The primary defect is the missing `.rstrip()` (or `.strip()`) call on `line[3:]`. Fixing it
there eliminates the secondary mismatch automatically — no change to the enrichment step is
needed.

**How to verify the fix**:

A reproducer test should:
1. Construct a `CONVENTIONS.md` content string where the `## Migration Patterns` heading line
   has two trailing spaces: `"## Migration Patterns  \nAdd Index::create() for all FK columns.\n"`
2. Pass this content through the convention conformance analysis function.
3. **Before the fix**: assert that `"Migration Patterns"` is NOT found in `discovered_conventions`
   (confirming the bug).
4. **After the fix**: assert that `"Migration Patterns"` IS found in `discovered_conventions`
   and that the task Implementation Notes include the string
   `"Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns."`.

## Affected Files Summary

- **`plugins/sdlc-workflow/skills/plan-feature/SKILL.md`** — heading extraction loop and
  convention-to-task enrichment logic; both the defect site and the silent-skip consequence

## Suggested Approach

Change the heading extraction from:

```python
section_name = line[3:]
```

to:

```python
section_name = line[3:].rstrip()
```

This is a single-character fix. `.rstrip()` (right-strip) is preferred over `.strip()` because
leading spaces after `"## "` would indicate intentional indentation in the heading text, whereas
trailing spaces are universally noise in Markdown headings.

## Reproducer Strategy

- Add a new eval fixture `evals/plan-feature/files/conventions-trailing-whitespace-mock.md`
  that mirrors `evals/plan-feature/files/conventions-mock.md` but with trailing spaces on every
  `## …` heading line.
- Run the plan-feature convention analysis against this fixture.
- Assert that the `"Migration Patterns"` section is present in the extracted `conventions` dict
  and that the generated task's Implementation Notes reference it.
- The test must fail before the `.rstrip()` fix is applied and pass after.
