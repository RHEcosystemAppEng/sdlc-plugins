## Determination

1. **What is broken:** plan-feature's convention conformance analysis drops any CONVENTIONS.md section whose `## ` heading line ends in whitespace. Task enrichment then never emits the "Per CONVENTIONS.md §<name>" note for that convention.
2. **Why it is broken:** heading extraction uses `section_name = line[3:]` without stripping whitespace, so `## Migration Patterns  ` is stored under the key `"Migration Patterns  "`. Enrichment looks up conventions by exact match (`convention_name in discovered_conventions`) with the clean name `"Migration Patterns"`, so the lookup fails. There is no warning path for an unmatched convention, so the failure is silent.
3. **Where it is broken:**

**Root Cause**

plan-feature's convention conformance analysis extracts CONVENTIONS.md section names with `line[3:]` and does not strip trailing whitespace. A heading like `## Migration Patterns  ` is stored as `"Migration Patterns  "`. The task-enrichment step then checks `convention_name in discovered_conventions` using the clean name `"Migration Patterns"`. The exact match fails, and because nothing warns on an unmatched convention, the convention is silently left out of the generated task's Implementation Notes.

**Affected Files**

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` — convention conformance analysis (heading extraction `section_name = line[3:]`)
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` — convention-aware task enrichment (`if convention_name in discovered_conventions`)

**Suggested Approach**

Normalize heading text at extraction by stripping leading and trailing whitespace, including a stray `\r` from CRLF files. Apply the same normalization to the lookup key. Add a visible warning when an expected convention cannot be matched, so future mismatches are not silent.

**Reproducer Strategy**

Add a plan-feature eval fixture where a CONVENTIONS.md heading has trailing whitespace (`## Migration Patterns  `). Add an eval case for an FK-migration feature that asserts the generated Implementation Notes include `Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns.` The case fails before the fix (the note is absent) and passes after.
