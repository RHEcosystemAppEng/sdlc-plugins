## Root Cause Analysis

### Root Cause

**What is broken:** plan-feature's convention conformance analysis builds its map of
CONVENTIONS.md sections using the raw heading text, without stripping trailing whitespace.

**Why it is broken:** the heading extraction uses `section_name = line[3:]`, which keeps every
character after `"## "`. A heading such as `## Migration Patterns  ` is stored under the key
`"Migration Patterns  "`. The convention-aware task enrichment step then performs an exact
match (`if convention_name in discovered_conventions`) using `"Migration Patterns"`, which
fails. There is no fallback or warning on a miss, so the convention is silently dropped from
the generated task's Implementation Notes. The same failure occurs for headings ending in tabs
or `\r` (CRLF line endings), since lines are split on `'\n'` only.

**Where it is broken:**

### Affected Files

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` — convention conformance analysis,
  CONVENTIONS.md heading extraction (`section_name = line[3:]`) — **primary defect**
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` — convention-aware task enrichment
  (`if convention_name in discovered_conventions`) — exact-match lookup with no warning on miss
- `evals/plan-feature/files/conventions-mock.md` — existing fixture lacks the trailing-whitespace
  case (test gap, not a defect)

### Suggested Approach

1. Normalize heading text at extraction time: strip leading/trailing whitespace (including
   tabs and `\r`) from the section name before using it as a map key.
2. Make the enrichment lookup robust to the same normalization (compare normalized names on
   both sides).
3. Emit a visible warning when an expected/relevant convention cannot be matched, instead of
   silently skipping it.

Single root cause in a single file — no decomposition needed. No persistence impact: the
convention map is computed in-memory per run; no data migration is required.

### Reproducer Strategy

Add a plan-feature eval fixture (based on `evals/plan-feature/files/conventions-mock.md`) whose
CONVENTIONS.md contains `## Migration Patterns  ` (two trailing spaces) followed by
`Add Index::create() for all FK columns.`, paired with a feature that needs a migration with
foreign keys. Assert that the generated task's Implementation Notes contain
`Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns.`
(section name without trailing whitespace). Before the fix this assertion fails (convention is
absent); after the fix it passes.
