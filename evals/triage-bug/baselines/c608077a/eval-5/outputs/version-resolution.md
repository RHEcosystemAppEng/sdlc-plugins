## 4.5.2 – Extract version from description

Environment / Version section content (verbatim):

> Not sure which version — using whatever is deployed on staging.

Patterns checked:

| Pattern | Example | Match in content |
|---|---|---|
| Explicit version number | `0.9.0`, `2.1.1` | None. The text contains no digits. |
| Product-prefixed version | `RHTPA 2.1.0` | None |
| Version keyword followed by a number | `version 1.2.3` | None. "version" appears ("Not sure which version"), but no number follows it. |

Why no version could be determined:

- The reporter says outright that they do not know the version ("Not sure which version").
- "Whatever is deployed on staging" points to a deployment environment, not a release. What staging runs changes over time, and the bug does not record a build, commit, or timestamp, so the text cannot be mapped to a release.
- The rule in 4.5.2 is: "If the section is empty, contains only vague text (e.g., 'latest', 'unknown'), or no version pattern can be extracted, skip to sub-step 4.5.6." This content is vague text and contains no version pattern.

**Result: no version identifier can be extracted.** Skip to 4.5.6.
