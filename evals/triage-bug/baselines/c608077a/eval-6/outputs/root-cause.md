## Root Cause

**What is broken:** plan-feature's convention conformance analysis drops CONVENTIONS.md sections
whose `## ` heading lines contain trailing whitespace.

**Why:** The heading extractor takes `section_name = line[3:]` without stripping whitespace, so
`## Migration Patterns  ` is stored under the key `"Migration Patterns  "`. Convention-aware task
enrichment then does an exact-match membership test
(`if convention_name in discovered_conventions`) with `"Migration Patterns"`, which fails. The miss
path has no warning/log, so the convention is silently omitted from Implementation Notes.

**Where:** `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`
- Convention conformance analysis — heading extraction (`line[3:]`)
- Convention-aware task enrichment — exact-match lookup on `discovered_conventions`

## Affected Files
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` — heading extraction and enrichment lookup
- `evals/plan-feature/files/conventions-mock.md` — fixture lacking the trailing-whitespace edge case

## Suggested Approach
- Normalize heading names at extraction: strip leading/trailing whitespace (including tabs and
  `\r` from CRLF line endings) from the text after `## `.
- Apply the same normalization to names used in lookups so both sides compare cleanly.
- Emit a visible warning when a convention referenced/expected cannot be matched, instead of
  silently skipping.

## Reproducer Strategy
- Add a plan-feature eval fixture whose CONVENTIONS.md contains `## Migration Patterns  ` (two
  trailing spaces) with body `Add Index::create() for all FK columns.`, driven by a feature that
  needs a migration with foreign keys.
- Assert the generated task's Implementation Notes contain
  `Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns.`
- Before the fix the assertion fails (convention absent); after the fix it passes.

## Persistence impact
None — no database persistence; no data migration required.
