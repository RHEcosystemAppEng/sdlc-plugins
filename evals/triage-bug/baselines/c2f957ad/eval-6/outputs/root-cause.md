## Root cause determination

The enrichment step later checks membership by exact string match (`if convention_name in discovered_conventions`). `"Migration Patterns"` does not equal `"Migration Patterns  "`, so the check fails. That branch has no else, warning, or log, so the failure is invisible.

   - `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`, in convention-aware task enrichment (`if convention_name in discovered_conventions`). This is where the silent drop happens, because there is no warning for conventions that don't match.

**Root Cause**

plan-feature's convention conformance analysis extracts `CONVENTIONS.md` section names with `line[3:]` and does not strip whitespace. A heading such as `## Migration Patterns  ` is stored under the key `"Migration Patterns  "`. The task-enrichment step then looks up conventions by exact name (`"Migration Patterns"`), the lookup misses, and the convention is skipped. Unmatched conventions produce no warning, so the drop is silent.

**Affected Files**

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`: convention conformance analysis heading-parsing loop (`section_name = line[3:]`)
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`: convention-aware task enrichment (`if convention_name in discovered_conventions`)

**Suggested Approach**

Normalize heading text when it is extracted, by stripping leading and trailing whitespace including `\r`, so stored keys match the canonical section names. Also add a visible warning when an expected convention cannot be matched, so future mismatches are reported instead of dropped. No data migration is required, because the parsed names exist only in memory while the task is generated.

**Reproducer Strategy**

Add a plan-feature eval fixture `CONVENTIONS.md` with `## Migration Patterns  ` (trailing whitespace) and a feature needing an FK migration. Assert that the generated Implementation Notes contain "Per CONVENTIONS.md §Migration Patterns: add `Index::create()` for all FK columns." This fails on the current code and passes after the fix.
