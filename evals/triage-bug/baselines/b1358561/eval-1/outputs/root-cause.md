## Root Cause Analysis

**Root Cause**

plan-feature's convention conformance analysis takes each `CONVENTIONS.md` section name with `section_name = line[3:]`. This keeps everything after the `## ` prefix, including trailing whitespace. The heading `## Migration Patterns  ` is therefore stored under the key `"Migration Patterns  "`. The task-enrichment step later checks `if convention_name in discovered_conventions` with the clean name `"Migration Patterns"`. The exact match fails, and because a miss has no else branch or warning, the convention is skipped silently. As a result, the generated task's Implementation Notes leave out `Per CONVENTIONS.md §Migration Patterns: ...`.

- **What is broken:** convention section-name extraction does not strip trailing whitespace from heading lines.
- **Why it is broken:** `line[3:]` slices the raw line with no `.strip()`/`.rstrip()` normalization. The later lookup is exact-match and has no warning when a match fails.
- **Where it is broken:** the convention lookup in `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`.

**Affected Files**

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`
  - Convention conformance analysis: the heading extraction loop (`section_name = line[3:]`). This is the defect.
  - Convention-aware task enrichment: the exact-match lookup (`if convention_name in discovered_conventions`), which fails silently.
- `evals/plan-feature/files/conventions-mock.md` is the existing fixture. It has no trailing-whitespace headings, so the case is not covered.

**Suggested Approach**

1. Normalize extracted heading text by stripping leading and trailing whitespace before using it as the section-name key.
2. Apply the same normalization to the lookup key in the enrichment step, so both sides compare clean names.
3. Optional hardening: if a convention section that should apply is not found, log a warning instead of dropping it silently.

**Reproducer Strategy**

Add a plan-feature eval fixture whose `CONVENTIONS.md` contains a heading with trailing whitespace (`## Migration Patterns  ` followed by `Add Index::create() for all FK columns.`). Run plan-feature against a feature that needs a database migration with foreign keys. Assert that the generated task's Implementation Notes contain `Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns.` The assertion fails before the fix because the convention is missing, and passes after it. The section name in the output must not contain trailing spaces.

**Persistence impact:** none. The extracted section names are used in memory only, so no data migration is needed.
