## Root Cause

The plan-feature skill's convention heading extraction uses `line[3:]` to parse
`## ` headings from `CONVENTIONS.md`, but does not strip trailing whitespace.
When a heading line contains trailing spaces (e.g., `## Migration Patterns  `),
the extracted section name becomes `"Migration Patterns  "` (with trailing spaces).
The downstream convention-matching logic uses exact string comparison
(`if convention_name in discovered_conventions`), which fails because the lookup
key `"Migration Patterns"` does not match the dictionary key
`"Migration Patterns  "`. The convention is silently omitted from the generated
task with no warning or error logged.

## Affected Files

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- convention heading
  extraction loop: `section_name = line[3:]` does not call `.strip()` or
  `.rstrip()` on the extracted heading text.
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- convention-aware task
  enrichment: `if convention_name in discovered_conventions` performs exact-match
  lookup against unstrippped keys.

## Suggested Approach

Apply `.strip()` (or `.rstrip()`) to the extracted heading text at the extraction
point: change `section_name = line[3:]` to `section_name = line[3:].strip()`.
This normalizes the dictionary key so that downstream lookups succeed regardless
of trailing whitespace in the source file. Consider also adding a defensive
`.strip()` on the lookup side for belt-and-suspenders safety.

## Reproducer Strategy

1. Create a test fixture `CONVENTIONS.md` with trailing whitespace on at least
   one heading line (e.g., `## Migration Patterns  ` with two trailing spaces).
2. Run the convention extraction logic against this fixture.
3. Assert that the extracted section name equals `"Migration Patterns"` (without
   trailing spaces).
4. Assert that the convention-aware task enrichment includes the expected
   convention reference in the generated Implementation Notes.
5. The reproducer test should fail before the fix (extracted key includes trailing
   spaces, lookup misses) and pass after the fix (key is stripped, lookup succeeds).
