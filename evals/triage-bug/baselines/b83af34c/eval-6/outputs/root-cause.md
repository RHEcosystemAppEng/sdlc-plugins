# Step 4 -- Root Cause Analysis: ACME-500

## Root Cause

The plan-feature skill's convention conformance analysis extracts CONVENTIONS.md section headings using `line[3:]`, which does not strip trailing whitespace. When a heading line contains trailing spaces (e.g., `## Migration Patterns  `), the extracted section name includes those spaces (`"Migration Patterns  "`). The subsequent convention-aware task enrichment step performs an exact string match against the expected clean name (`"Migration Patterns"`), which fails because the keys do not match. The convention is silently dropped from the generated task description with no warning or error logged.

## Affected Files

| File | Symbol/Location | Defect |
|------|----------------|--------|
| `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` | Convention conformance analysis -- heading extraction (`line[3:]`) | Does not strip trailing whitespace from heading text |
| `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` | Convention-aware task enrichment (`if convention_name in discovered_conventions`) | Exact match fails on keys with trailing whitespace; no fallback or warning |

## Suggested Approach

1. Add `.strip()` to the heading extraction: change `section_name = line[3:]` to `section_name = line[3:].strip()` so that trailing whitespace on heading lines is normalized before storing as dictionary keys.
2. Optionally, add a diagnostic warning when stripped whitespace differs from original, to help identify malformed CONVENTIONS.md files.
3. The fix is localized to a single code path -- no architectural changes needed.

## Reproducer Strategy

1. Create a test CONVENTIONS.md fixture file with trailing whitespace on at least one heading line (e.g., `## Migration Patterns  ` with 2+ trailing spaces).
2. Run the plan-feature convention conformance analysis against this fixture.
