## Root Cause Analysis

**Root Cause**

The plan-feature skill's convention conformance analysis takes the heading text from
`CONVENTIONS.md` with `section_name = line[3:]` and does not strip whitespace. A heading such as
`## Migration Patterns  ` is stored under the key `"Migration Patterns  "` (with trailing spaces).
The convention-aware task enrichment step then looks up `"Migration Patterns"` with an exact
`in` check. The lookup misses, so the convention never reaches the task's Implementation Notes.
The enrichment step has no handling for a miss, so nothing is logged and the convention is
dropped silently.

- **What is broken:** heading extraction keeps trailing whitespace, so convention-name matching fails.
- **Why:** there is no `strip()` / `rstrip()` on the extracted heading, and no warning when a
  heading does not match.
- **Where:** the plan-feature convention lookup in `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`.

**Affected Files**

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`
  - Convention conformance analysis, heading-extraction loop (`section_name = line[3:]`): the defect
  - Convention-aware task enrichment (`if convention_name in discovered_conventions`): the silent miss

**Suggested Approach**

1. Normalize the heading text when extracting it: strip trailing (and leading) whitespace,
   including tabs and `\r` from CRLF files, before using it as the conventions key.
2. Make the enrichment step stop failing silently: when an expected convention cannot be found,
   or a `CONVENTIONS.md` heading does not match any expected name, log a warning.
3. No data migration is needed. The conventions map is built on every run and never persisted.

**Reproducer Strategy**

Add a plan-feature eval fixture whose `CONVENTIONS.md` contains `## Migration Patterns  ` (two
trailing spaces) followed by `Add Index::create() for all FK columns.` Run plan-feature against
a feature that needs an FK migration, then assert that the generated task's Implementation Notes
contain `Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns.` The
section name must have no trailing spaces. This assertion fails before the fix (the note is
missing) and passes after it.
