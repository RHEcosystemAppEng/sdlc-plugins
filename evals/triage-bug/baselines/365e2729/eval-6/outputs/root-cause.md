# Step 4 – Root Cause Analysis: ACME-500

## Determination

1. **What is broken:** plan-feature's convention conformance analysis drops a
   `CONVENTIONS.md` section without any message when that section's heading has trailing
   whitespace. The generated task's Implementation Notes then leave out the convention.
2. **Why it is broken:** the heading extraction `section_name = line[3:]` keeps the rest of
   the line as-is, without trimming. `## Migration Patterns  ` produces the key
   `"Migration Patterns  "`. The later exact-match lookup
   `if convention_name in discovered_conventions` compares that key with
   `"Migration Patterns"` and fails. There is no fallback or warning when a lookup misses,
   so nothing tells the user.
3. **Where it is broken:** `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`:
   - Convention conformance analysis: heading extraction (`line[3:]`), which is the primary defect.
   - Convention-aware task enrichment: exact-match lookup with no warning when it misses.
4. **How to verify the fix:** add a plan-feature eval fixture whose `CONVENTIONS.md` has
   `## Migration Patterns  ` (trailing spaces). Assert that the generated task's
   Implementation Notes contain
   `Per CONVENTIONS.md §Migration Patterns: add Index::create() for all FK columns`.
   This fails before the fix and passes after it.

## Root cause comment (would be posted to ACME-500 via `jira.add_comment`, ADF format)

> **Root Cause**
>
> plan-feature's convention lookup reads `CONVENTIONS.md` headings with `line[3:]` and
> does not strip trailing whitespace. A heading like `## Migration Patterns  ` is stored
> under the key `"Migration Patterns  "`, so the exact-match lookup for
> `"Migration Patterns"` in the task-enrichment step fails. The miss is not logged, so the
> convention disappears from the generated task's Implementation Notes without any warning.
> CRLF line endings (a trailing `\r`) cause the same failure for every heading.
>
> **Affected Files**
>
> - `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`, convention conformance analysis (heading extraction `section_name = line[3:]`)
> - `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`, convention-aware task enrichment (`if convention_name in discovered_conventions`)
>
> **Suggested Approach**
>
> Normalise heading names at extraction time by trimming surrounding whitespace, including
> `\r`, so keys match the canonical section names. As defence in depth, also surface a
> warning when a relevant convention cannot be matched, instead of skipping it silently.
>
> **Reproducer Strategy**
>
> Add a plan-feature eval fixture (modelled on `evals/plan-feature/files/conventions-mock.md`)
> whose `## Migration Patterns  ` heading has trailing whitespace. Add an eval case asserting
> that the generated Implementation Notes include
> "Per CONVENTIONS.md §Migration Patterns: add `Index::create()` for all FK columns."
