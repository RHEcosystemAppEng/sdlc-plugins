# Step 4 -- Root Cause Analysis: ACME-500

## Root Cause Determination

### 1. What is broken

The plan-feature skill's convention conformance analysis fails to match `CONVENTIONS.md` section headings that contain trailing whitespace. When a heading like `## Migration Patterns  ` (with trailing spaces) is parsed, the extracted section name retains the trailing whitespace, producing a dictionary key of `"Migration Patterns  "`. The subsequent convention lookup uses a clean key `"Migration Patterns"`, which does not match, and the convention is silently dropped from the generated task description.

### 2. Why it is broken

The heading extraction code uses `line[3:]` to extract the section name after the `## ` prefix. This slice operation preserves all characters after position 3, including any trailing whitespace. The extracted name is stored as-is in the `conventions` dictionary. When the task enrichment step later looks up convention names using exact string matching (`convention_name in discovered_conventions`), the trailing whitespace causes a mismatch. There is no `.strip()` or `.rstrip()` call to normalize the heading text, and no warning is logged when a convention lookup fails.

### 3. Where it is broken

| Location | Defect |
|----------|--------|
| `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- convention heading parser | `section_name = line[3:]` does not strip trailing whitespace |
| `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- task enrichment lookup | `if convention_name in discovered_conventions` silently fails on mismatch with no warning |

### 4. How to verify the fix

A reproducer test should:

1. **Setup**: Create a `CONVENTIONS.md` fixture with trailing whitespace on a heading line (e.g., `## Migration Patterns  ` with two trailing spaces).
2. **Action**: Run the convention heading extraction logic against this fixture.
3. **Assert (before fix)**: The convention name in the dictionary has trailing whitespace, causing lookup failure -- the convention is not included in the generated output.
4. **Assert (after fix)**: The convention name is correctly stripped to `"Migration Patterns"` and the lookup succeeds -- the convention IS included in the generated task's Implementation Notes with the expected reference format.
