# Step 4 -- Root Cause Analysis: ACME-510

## Root Cause

The `/api/v2/advisories` endpoint's date-range filtering code path does not compute
or attach pagination headers (`X-Total-Count` and `Link`) to the response. When
`publishedAfter` and/or `publishedBefore` query parameters are present, the handler
takes a filtered query path that returns the correct filtered result set in the response
body but bypasses the pagination header construction logic. The unfiltered path correctly
performs a separate total count query and passes the count to the pagination header
builder, but this step is absent from the filtered path.

## What Is Broken

The filtered advisories query path omits the total count computation that feeds the
pagination header builder. Without a total count, the `X-Total-Count` header cannot be
set and the `Link` header (which requires knowing whether more pages exist) cannot be
constructed.

## Why It Is Broken

When the date-range filter support was added to the advisories endpoint, the count query
was either not included in the filtered code path or the filtered path was implemented
as an early-return branch that bypasses the shared pagination header logic used by the
unfiltered path.

## Where It Is Broken

- **Endpoint handler**: The advisories endpoint handler (likely in `src/api/v2/advisories.rs`
  or equivalent) where the filtered query path diverges from the unfiltered path.
- **Query/repository layer**: The query function for filtered advisories that does not
  perform a companion count query with the same filter predicates.
- **Pagination header builder**: Not broken itself, but not invoked (or not supplied with
  a count) in the filtered code path.

## How to Verify the Fix

A reproducer test should:

1. Call `GET /api/v2/advisories?publishedAfter=2025-01-01&publishedBefore=2025-06-30&limit=10`
   against a test instance with sufficient advisory data.
2. Assert that the response includes the `X-Total-Count` header with the correct count
   of advisories matching the date-range filter.
3. Assert that when more pages exist, the response includes a `Link` header with a
   `rel="next"` entry pointing to the next page.
4. Assert that the `X-Total-Count` value reflects the filtered count (not the total
   unfiltered count).
