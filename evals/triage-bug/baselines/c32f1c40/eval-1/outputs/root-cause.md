## Root Cause

The plan-feature skill's convention conformance analysis extracts CONVENTIONS.md
section headings using `line[3:]`, which preserves trailing whitespace from the
source file. When a heading line contains trailing spaces (e.g., `## Migration Patterns  `),
the extracted section name becomes `"Migration Patterns  "` instead of `"Migration Patterns"`.
The subsequent convention lookup uses exact string matching (`if convention_name in
discovered_conventions`), which fails because the key has trailing whitespace that the
lookup value does not. The convention is silently dropped with no warning or error logged.

## Affected Files

- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- convention conformance
  analysis section, heading extraction logic (`line[3:]` without `.strip()`)
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md` -- convention-aware task
  enrichment section, exact-match lookup (`if convention_name in discovered_conventions`)

## Suggested Approach

1. Apply `.strip()` to the extracted heading text: change `line[3:]` to `line[3:].strip()`
   in the convention conformance analysis logic. This normalizes the section name by
   removing leading and trailing whitespace before storing it as a dictionary key.
2. Optionally, also normalize the lookup key in the task enrichment step for defense
   in depth.
3. Consider adding a warning log when a CONVENTIONS.md heading is parsed, to aid
   future debugging of similar issues.

## Reproducer Strategy

Create a test fixture `CONVENTIONS.md` that includes a heading with trailing whitespace
(e.g., `## Migration Patterns  ` with two trailing spaces). Run the convention conformance
analysis against this fixture and assert that the convention IS matched and included in the
generated task's Implementation Notes. The test should:

1. **Before fix**: assert that the convention is NOT found (confirming the bug exists).
2. **After fix**: assert that the Implementation Notes contain
   `Per CONVENTIONS.md Migration Patterns: add Index::create() for all FK columns.`
