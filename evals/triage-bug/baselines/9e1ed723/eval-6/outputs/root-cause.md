# Step 4 – Root Cause Analysis: ACME-500

## Determination

1. **What is broken**: plan-feature's convention conformance analysis does not recognize
   `CONVENTIONS.md` sections whose heading line has trailing whitespace. Convention-aware task
   enrichment then leaves those conventions out of the generated Implementation Notes and
   gives no warning.
2. **Why it is broken**: the heading is extracted with `section_name = line[3:]`, which keeps
   trailing whitespace (spaces, tabs, or `\r` from CRLF files). The extracted key
   (`"Migration Patterns  "`) then fails the exact-match lookup
   `if convention_name in discovered_conventions` against `"Migration Patterns"`. A miss
   is ignored, so the failure is invisible.
3. **Where it is broken**: `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`
   - Convention conformance analysis: the heading parse loop (`line[3:]`). This is the primary defect.
   - Convention-aware task enrichment: the exact-name lookup with no miss handling. This is a contributing factor (silent failure).
4. **How to verify the fix**: a reproducer eval fixture whose `CONVENTIONS.md` contains

## Root cause comment (would be posted to ACME-500 via `jira.add_comment`, ADF format)

**Root Cause**
plan-feature extracts `CONVENTIONS.md` section names with `line[3:]` and does not strip
whitespace. A heading such as `## Migration Patterns  ` produces the key
`"Migration Patterns  "`, which fails the exact-match lookup in convention-aware task
enrichment. A miss is not logged, so the convention is dropped silently.

**Affected Files**
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`: convention conformance analysis (heading extraction `section_name = line[3:]`)
- `plugins/sdlc-workflow/skills/plan-feature/SKILL.md`: convention-aware task enrichment (`if convention_name in discovered_conventions`)

**Suggested Approach**
Normalize heading text at extraction time by stripping leading and trailing whitespace,
including `\r`. Optionally normalize the lookup key the same way. Also report a visible
warning when a convention is expected but cannot be matched, so this kind of failure no
longer goes unnoticed.

**Reproducer Strategy**
Add a plan-feature eval fixture variant of `evals/plan-feature/files/conventions-mock.md`
whose `## Migration Patterns  ` heading has trailing whitespace. Add an eval case asserting
that the generated task's Implementation Notes contain
"Per CONVENTIONS.md §Migration Patterns: add `Index::create()` for all FK columns."
